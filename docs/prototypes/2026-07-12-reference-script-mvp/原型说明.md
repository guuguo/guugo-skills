# 双参考脚本 MVP 原型

status: "候选样稿，等待用户确认"
created_at: "2026-07-12"
source_of_truth:
  - "参考 A：冷调克制重逢"
  - "参考 B：暖调高冲突循环"

## 核心交互

输入 `reference_type=A/B` 与可选故事前提，输出一份固定结构的原创古装视频脚本。

## 本轮产物

- `样稿-A-销名.md`：8 秒双人冷调重逢。
- `样稿-B-第十八轮.md`：47 秒三人暖调循环困局。

两份样稿不是黄金样稿。只有用户确认“像参考的片感和脚本密度”后，才可作为技能中的示例或少样本参考。

## 本轮不验证

- 发布数据和流量。
- 分镜图、视频提示词和视频生成。
- 泛化到第三种参考风格。
