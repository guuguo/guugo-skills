## 3. 取舍判断与建议

### A《销名》

- **已保留的取舍**：把可见信息压在“旧名将烧、朱砂抹名、他要求停止销名”三件事上。8 秒不解释谁逼她销名，也不讲二人全部前史。
- **风险**：冷调留白如果没有足够强的演员表情和道具特写，可能只剩氛围，第一次观看的人未必马上读懂“她当年是在救他还是害他”。
- **建议**：先不改字句，后续若用户认为谜面太虚，只增加一个可视的身份压力信息，不增加旁白或第二个主要动作。

### B《第十八轮》

- **已保留的取舍**：用“熔星炉、星钥、潮汐、回溯”把参考的高冲突循环结构替换为全新事件系统，避免复用火场、剑和原三人关系。
- **风险**：47 秒内出现的专有名词较多；即使结构清楚，也可能让第一次观看者先记规则、后感受人物。
- **建议**：先交用户判断。若用户觉得信息密度过高，优先合并“潮汐”和“时轮”的解释，不动三人目标、五段失败闪回和结尾可见代价。
