# 素材启发检索：收敛问题与修订

## 评估范围

依据用户提供的执行日志、gg-drama-library 当前规范，以及当前素材库的作品清单与部分中后期案例。日志停在写查询记录之前，未提供最终回答，故只判断已呈现的探索路径，不断言最终完全没有发散。没有重跑视频、ASR、评论或平台数据，不修改素材库。

本次观察到库内 9 个作品目录，其中 6 个有案例，共 89 个案例文件；其余目录尚无案例。不沿用此前空库状态。广读目录后重点读取《回乡》14/15、《总裁让我住他家》6/17、《大佬X过气明星》16 的库内回合记录；只用已读材料说明迁移可能，不声称重看原片或认证爆款。

## 收窄原因

1. “匹配开头”被偏向处理成找原作开头，日志连续聚焦各剧开头集和《回乡》前四集。已有“原作集号不决定用途”只是禁止误判，没有要求主动去中后期找可前移回合。
2. 源素材与目标人设的条件混在一起。农村、腼腆倔强、儒雅尊重约束的是新作品，不代表素材原作必须同时具备；单个原角色不合不能排除局部互动。
3. 发散作为检索后的可选附加项。“匹配开头”未明确归为素材启发，且 3–5 条近似原例容易成为最终创意数量上限。
4. 迁移缺少具体动作：原作因果前提和关系许可没有被拆开，导致“依赖上一集”直接变成不可前移，而未尝试新建当场理由。
5. 部分库卡片的 mechanism 是重复句式，prerequisites 仅说“理解上集”。例如《回乡》14/15、总裁17的回合比机制摘要具体；这种摘要会抹掉可拆出的参考点。本次只增加读取与未来采集指引，没有擅自批量改库。

## 已改动

- “帮自己的故事匹配开头/情节”默认探索近似原例、跨集局部迁移和组合解法，用户明确只看原例时除外。
- 明确目标约束与源素材条件分离，匹配开头需主动读中后期与不同题材的互动；保持 Harness 阅读理解，不加入字符串匹配或评分工具。
- 新增 references/creative-transfer.md：选具体回合→辨明原作依赖→重建目标场景理由→映射目标人物→形成不同解法。允许一例多解、多例组合。
- 原例不是最终解法数量上限；素材充分时可给 6–10 个有差异点子，材料少也可一例多解，不为数量伪造出处。
- 交付按“来源→借用回合→新解法→迁移前提”展开，先广读已有材料，再定点复核候选，避免每次灵感任务扩大为全量重采。
- 数据约定补充具体机制和前置事实的写法，迁移依据存入现有 ideas.interaction/assumptions，不新建系统或改造稿。

## 第一性原理重整（替代前述逐项规则细化）

### 0. 删除检查

删除固定点子数量、近似/迁移/组合的类别配额、先报告再发散的排版要求、针对某类人物的重复例子与操作清单。这些都不是用户获得灵感的必要条件，还会诱导模型照着例子做出同一类点子。保留原始素材、表现数据、配置和证据规范；移除它们会损害用户明确要求的可追溯参考。

### 1. 问题本质

用户希望从可靠素材中得到可选择、可组合的不同创意，自行定稿。应优化每个点子实际增加的创作可能性，而不是全套条件相似度、点子数或流程完整度。用户已认可前次结果基本有用，不能把整个结果当失败样本。

### 2. 被质疑的假设

| 原假设 | 判断 |
| --- | --- |
| 来源越像目标越好 | 取消；参考价值取决于它能启发什么，目标约束作用于新构思。 |
| 多点子意味着发散好 | 取消；同一冲突、选择与回应换皮仍是变体。 |
| 必须规定几类路径和逐步变换 | 取消；Harness 能进行类比与组合，技能只需说明目标、依据和比较标准。 |
| 每次要完整报告原片与数据才能构思 | 调整；先读现有材料，关键出处按需回查，共用来源只介绍一次。 |
| AI 需要给出最佳路线并带用户收稿 | 取消；用户要保留取舍与定稿权。 |

### 3. 不可删的事实与需求

- 参考、原片时间、对白与表现数据须真实可追溯，分析和新构思须分开。
- 用户需要具体情境与互动，才能产生感受和进行选择。
- 一个来源可启发多个问题，多个来源可以组合；原作整套前情不必原封不动进入新情境，但新理由须说明。
- 用户明确的人物边界和授权仍有效，兴趣不等于定稿。
- 创意效果具有不确定性，规范与工具通过不能证明作品好看。

### 4. 最小重建

入口仅负责目标、配置、任务路由与共同底线；素材启发统一到 retrieval.md：理解需求、阅读素材、形成具体点子、比较点子间有意义的差异、交给人选择。旧 creative-transfer.md 留三行转向，维持已发给用户的链接，不再作为独立流程加载。

采用一个内容判断：遮住姓名、地点、道具，剩余冲突、选择与回应是否仍然相同？相同的视作同一解法的变体，按价值合并；有新的互动或观看获得的保留。该判断不编码为程序，不设分数、数量或类别配额。

四个相关文件合计 8446→3266 字符，192→91 行；不修改数据契约、媒体处理、快照、脚本、配置或现有素材。

### 5. 验证与边界

技能结构、Markdown 引用、YAML 和自动触发配置检查通过；代码未改，不重跑脚本和媒体测试。按用户所给 A–E 回答做桌面检查：保留 A 的跨集前移、B/C 的跨作组合与 E 的来源区分；A/B/D 都涉及拒绝帮助或白拿，应比较各自新增加的互动价值，不能仅因场景不同计作充分发散，也不因此自动全部删除。此为内容评估，不是新会话的实际前向测试。

接受的取舍：减少程序式规定，将探索与比较交给 Harness 的理解能力；其稳定效果还需真实使用反馈。尚未修复的证据发布校验问题与本次创作指引重整分开记录，未宣称解决。
