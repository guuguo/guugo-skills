# 全库声画对应与完整桥段补解析

## 目标与范围

按最新 gg-drama-library 和 gg-video-analysis 规范，核查整个已采集库，修复逐句说话人与画面对应缺失、桥段过度压缩、节奏过程丢失和分析套话污染。目标是下游仅阅读文本，就能跟随原作的铺垫、生活动作、对白、反应、停留与转场，不需要每次构思重新看视频。

从 `~/.config/gg-drama-library/config.json` 读取 library_root。当前约定目录为 `/Volumes/Seamless SSD/素材库/短剧桥段素材库`；执行时核对配置与卷挂载。

范围是执行开始时库内全部作品、已采集集数、已有证据包和桥段，不限《回乡》或某几个集数。先盘点真实文件与版本，不能沿用旧对话里的集数或案例总数。已有合格记录核验后保留，只补缺项和修错项。未采集的集数、缺失原片或仅有试看记为缺口；不把本任务扩大为发现新作品或补齐所有未采集剧集。

## 执行方式

1. 在库内 `reviews/<本次唯一批次>/` 保存执行清单与修订前快照。逐作品、逐集记录版本、现有产物、证据覆盖与具体缺口。库里可能有其他人刚更新的记录，修改前重新读取，发现同文件仍在并行修改先协调，不能用旧副本覆盖。
2. 优先复用原片、音轨、已有帧及真实时间映射、ASR、校对文本、观察记录。字幕可见时间点和观察窗口是有效已有信息，不一律改成“待核验”。原片版本、时长或顺序存在冲突时核实对应版本，不凭回忆、旧摘要或本任务说明决定原作顺序。
3. 对照本集已有材料检查整个已采集范围；只对不足以判断的部分补帧、局部原速观看或听审。若记录普遍缺失过程，回看范围应扩至足以完成该集核验，不能只检查几句字幕后宣称全集完整。缺新 ASR 不等于必须重跑 ASR；确有转写缺口且现有字幕/声音不足时，才按视频技能规范使用。
4. 先修 observations 与 text_review，再修单集 events、tracks、state_ledger 及 cases。按实际依赖修正受影响的跨集连接、阶段和作品分类，不把全剧结论倒灌到第一集。来源表现数据保留原始日期与快照，不因本次补解析伪装成新采集数据。
5. 每集对照证据检查后，仅读文字检查是否能跟随完整过程。完成本批结构校验后导出索引；若既有结构错误阻止导出，列出具体错误与影响，不绕过校验或声称目录已更新。无需每修一句话就跑一遍全库维护。

## 必须补到什么程度

### 对白与画面对应

每句采用对白在现有 observation/action 文本内对应说话人、可确定的听话对象、画内对白/画外音/旁白或未知、当时镜头中的人物与动作，以及可见回应。多人对话分别归属，不能整段只写“父母讨论”或全部归给一个 actor。画面中的人未必在说话；只在场未必听见。

清晰烧录字幕与实际声音用于核对，原始 ASR 不覆盖。未辨认说话人、未观察反应、未听审与确认没有发生分别记清。对白跨镜头时保留声音与切画面的先后或重叠，不机械拆成一语一镜。采用文字、观察、事件与桥段保持一致。

### 完整过程与节奏

按原片呈现顺序保留铺垫、生活过程、互动、反应、停留、转场与结束。不同场景和时间的事件不能挤成一个 action→response；走路、洗脸、干活、等待或环境镜头不因缺冲突而删掉。持续同一动作可合并，不按固定拍数、每镜头一条或固定秒数机械切割。

每拍引用对应证据范围。已有单帧时刻可作锚点，不能当成整句起止；已有观察窗口可继续使用，边界未核实注明精度。需要表现停顿和动作持续时用实际观看、听审核实；稀疏帧不能填满中间过程，ASR 空白不能证明静默。不得通过补写动作或平均分配秒数让记录看起来完整。

### 事实与分析

保留可验证事件，角色说法与事实分开，心理、因果、受众与情绪判断注明依据和不确定性。移除当前已重做条目中脱离本集证据的全剧套话、可替换物件、改造建议和公式；旧分析先留快照，mechanism 按新契约保留 `{}`。不把“更甜”“身份差出现”复制为所有轨道节点，节点关联实际事件，无依据留空或未知。

## 数据与资源边界

- 不改原片，不覆盖原始 ASR 或旧帧；新增证据放新目录，记录来源版本。保留稳定 ID 与现有有效引用，必须调整范围引用时同步检查受影响记录。
- 不修改技能、创作稿、已确认人设或项目定稿；发现项目引用受影响，列入报告，不借修资料改剧情。
- 文字读取可批量；媒体与模型重处理沿用既有资源预检及串行规范。不全量解码图片驻留、不拼整剧大图、不并行常驻多个 ASR 模型，不绕过内存门禁。
- 不为了完成率补造未知。无法完成的项目保留 partial/disputed/insufficient 等恰当状态及原因，不把仅有工具产物或旧 usable 标志当成已验收。

## 交付与验收

在本批 reviews 目录交付一份逐集清单及结果说明，列出：作品/集号、是否已核查、已补内容、实际观看/听审范围、当前状态、未决缺口、更新文件、旧快照与证据路径，以及校验和索引结果。未核查与核查后无须修改分开统计；进度说明不能替代全范围清单。

验收要同时满足：

1. 全部已采集条目均有处理结论；未完成部分明确列出，抽样通过不称全库通过。
2. 对白、说话人、同期画面、反应与时间依据可对应；未知如实保留，影响理解的缺口未解决不能称完整。
3. 仅读桥段文本能跟随铺垫到结束及其疏密，不只看到高光动作或两句摘要。
4. 已有有效事实与时码保住；新增或修正信息有实际证据，不以扩写字数或增加拍数冒充补解析。
5. 上游观察、校对文本、单集、桥段及受影响跨集资料引用一致，结构校验结果和目录导出状态有实际执行证据。
