## 当前理解

- 需求目标：做一个面向本机 macOS 的清理诊断技能，优先快速定位磁盘/swap 大户，给出安全清理建议，并通过电脑印象逐步变聪明。
- 本期成功标准：新增技能规划清晰，后续实现者能按规划创建 `skills/gg-clean-mac/`，实现快速模式、深度模式、电脑印象更新和安全清理边界；快速模式只加速证据收集与决策表达，不跳过清理确认。
- 主要非目标：本期不直接实现技能；技能默认不删除文件；不把聊天软件数据当普通缓存删除。

## 已确认结论

- 技能名为 `gg-clean-mac`。
- 目标项目为 `guuguo-skills`。
- 需要快速模式。
- 需要每次扫描后更新电脑印象。
- 电脑印象方案采用 `~/.agents/state/gg-clean-mac/computer-impression.json`，一个 JSON 文件内包含 `machine_summary`、`hotspots`、`preferences`、`recent_scans`、`known_incidents`。
- 单次多轮清理采用“对话内看板 + 结束后摘要入印象”；电脑印象不保存过程流水账。
- 电脑印象采用 JSON 作为唯一长期源文件；Markdown 只用于展示。
- 企业微信这类占用应优先解释并引导 App 内清理。
- 所有清理行为都必须用户确认；快速模式不得跳过确认。
- 候选项信息必须足够支持确认：来源、用途、删除影响、重建方式、网络/外网/VPN 成本都要尽量说明。
- 首版必须包含交互协议、电脑印象 JSON schema 和常见目录知识库，避免实现时自由发挥。

## 推荐假设

- 电脑印象属于个人机器状态，不随技能源码提交。
- 电脑印象不做 Markdown/JSON 双源维护，避免不一致。
- 清理动作必须默认关闭，只有用户逐项确认具体清理项后才执行。
- 输出固定分为：当前状态、超级占用、缓存大户、App 内清理、谨慎处理、下一步建议、电脑印象更新。
- 快速模式的第一批路径应包含本机已发现的大户。
- 每个可清理候选应尽量给出路径、大小、来源、用途、风险、建议命令、重建方式、网络/VPN 成本和预期收益，让用户快速确认或拒绝。
- 用户确认语法建议采用编号式，例如 `清理 1`、`清理 1 3`、`跳过 2`、`暂缓 4`、`深扫 5`；泛泛的“可以”“都清了”“帮我清理”不能触发实际删除。
