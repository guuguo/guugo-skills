# 情绪爆发点优先的一分多钟故事创作预设

本预设用于用户只说“写一个”“来一个”“再想一个”，只给宽泛题材方向，或把选题交给 Agent 时，分阶段产生抖音 AI 情绪短故事。先读取 `emotional-climax-first.md`，锁定强钩子、情绪起伏和爆发点，再倒推最少剧情。只有用户要求参考案例、当前任务确需迁移已验证机制，或需要核对具体源片事实时，才读取 `case-library.md` 并选择最多两篇相关案例；不得默认加载《逆洪救母》或其他历史案例。除非用户本轮要求或项目锁定配置明确允许多场景，完整故事只保留一个主场景；真实阻力、有价选择和首遍可懂的情绪回报是生产硬门，不能被钩子或煽情覆盖。

## 已加载案例的预检

只有执行前回执已经公开加载案例时，内部写三行：

1. 当前借鉴案例的可迁移机制是什么；
2. 当前案例最应避免复制或误读的是什么；
3. 成片发布后用哪个指标验证本次迁移。

案例只用于修正判断，不得为了“像案例”改变用户已选关系、题材或爆发点。公开爆款提供机制候选，自有A/B提供更接近本项目的验证方向；二者都不能升级为平台普适因果。

## 调用方式

以下自然语言会进入故事工作流；只给宽泛方向或让Agent选题时先路由到C01，选中方向后才进入本预设的完整故事阶段：

```text
写一个一分多钟、泪点足的抖音 AI 短故事
```

```text
来个红军方向的
```

```text
题材你自己发散，给我最值得拍的一个
```

正式命令是可选的高级用法：

```text
$gg-douyin-ai-video 创作｜方向：天下无拐
```

或：

```text
按情绪爆发点预设创作：前世今生·红军
```

可选参数：

```text
数量：1
时长：75–95 秒
情绪：泪 / 燃泪 / 笑泪 / 克制
钩子：自动 / 答案前置 / 冲突谜面 / 看似很坏 / 危险倒计时 / 反常动作
主场景：自动或用户指定
短回忆：允许 / 禁用
事实模式：虚构合成人物 / 史实核验
输出：完整稿 / 故事卡 / 仅故事正文
禁用：用户指定的题材、动作、物件或表达
```

用户只给方向、只给情绪，或完全不指定题材时，不为上述可选项追问。若用户没有说“直接写”，先读取 `topic-selection-stage.md` 输出方向候选并等待选择；用户明确要求直接写时，按硬门和相对比较采用最推荐方向。用户明确指定的参数优先。

## 两阶段工作方式

### 第一阶段：情绪爆发点与方向候选（C01）

适用于用户说“先发散”“给几个方向”“题材你选”，或尚未锁定具体故事时。即使用户说“写一个”，只要没有同时说“直接写／你直接选第一名”，也先读取 `topic-selection-stage.md`，核验当前可用信号，输出方向候选卡和推荐排序，然后停止，等待用户选编号或组合方向。

即使用户给了“红军”“反拐”“父女”等宽泛母题，也要先在该母题下发散不同的关系缺口、爆发动作和对方反应，再选择场景与钩子切口。

### 第二阶段：完整故事（C02）

用户选中方向后，再按本文件的情绪爆发点倒推预设写完整故事。用户明确说“直接写”“你选最好的”或“按第一名写”时，不停顿，由 Agent 先选爆发点最强且首遍最易理解的候选，再进入本阶段。

## 自主发散规则

当用户没有给完整参数时，由 Agent 自动补齐：

- **只给题材方向**：默认先在该方向内输出可选择的关系缺口、爆发动作、对方反应和余波，再补当下困境、钩子与主场景；用户说“直接写”时才按硬门和相对证据选择最推荐方向；
- **只给情绪方向**：自主选择一个近期未重复、能形成真实阻力的题材；
- **完全开放选题**：读取 `topic-selection-stage.md`，优先选择有当前热度信号或长期关系共鸣、又能压进一个主场景的方向；默认先让用户选择；
- **用户说“再来一个”**：避开本对话已使用的核心关系、主场景、钩子类型、核心物件和结尾动作，不做换皮稿；
- **用户说“选最好的”“直接写”**：候选先按情绪爆发点、人话复述、提前知情测试排序，再比较生产硬门和冷启动潜力，直接交付最推荐的一篇；
- 不向用户展示参数补全过程、淘汰稿或长篇方法说明，除非用户要求查看。

只有以下情况才提问：用户要求互相冲突；指定真实人物或案件但身份不清；缺失信息会导致事实风险、伦理风险或完全不同的创作方向。普通风格选择由 Agent 自行决定。

## 默认值

- 数量：1 篇完整故事；
- 时长：75–95 秒；
- 画幅：继承`runtime-contract.md`已解析的本轮配置，不在本预设另设默认值；
- 核心关系：1 个；
- 主要人物：2 人；
- 主场景：1 个；
- 相邻微空间：允许，但不得成为第二故事现场；
- 短回忆：最多 1 次、3–8 秒、1–3 镜头，只补一个事实；
- 对白：最多 8 句，每句尽量不超过 14 个汉字；
- 核心物件：0–1 个；不强制象征物或三次状态变化，只有自然参与爆发动作时才保留；
- 钩子：自动选择最适合题材且与近期同批故事不重复的类型；
- 输出：完整时间码脚本＋创作者预检；正式生产评审和观众盲测由独立子代理另行输出。

## 事实与题材预检

- 用户方向涉及当前热点、政策、平台趋势或现实案件时，先核验最新事实；
- 涉及红色历史、真实人物、部队番号、地名、日期和原话时，优先使用权威史料；无法核验时改用明确的虚构合成人物，不伪称真实事件；
- “前世今生”优先作为梦境、旧物触发或今昔视觉映照，不把玄学身份当作事实；
- 涉及反拐、未成年人、公安、医疗、法律或真实受害者时，不展示可复制的伤害方法，不猎奇消费创伤，不虚构真实身份；
- 题材方向只提供创作入口，不能代替真实阻力和人物选择。

## 候选池与停止条件

1. 围绕同一方向建立不少于 8 个“关系需要＋爆发动作＋对方反应＋余波”候选；
2. 先执行人话复述和情绪起伏两项硬测试；
3. 再诊断提前知情、无道具、对方反应和关系不可逆，但不因金句、揭晓、道具或直给煽情自动淘汰；
4. 优先保留前三秒钩子最强、至少有两次明显情绪转向、爆发点共鸣最强的候选；
5. 解释消失、真实阻力、有价选择和单主场景要求先执行硬筛选；次要完整性与 AI 生产难度只记录风险，不覆盖情绪排序；
6. 选择钩子、情绪振幅和关系投射最强的一篇；
7. 完稿后只执行创作者预检：核对用户硬要求、钩子、最低理解、可视化和明显逻辑错误；
8. 创作者预检可以在首次交付前修正明显违约点，但不打分、不判定生产放行、不模拟独立观众；
9. 需要成为正式候选或进入生产时，锁定当前版本，再由独立子代理读取 `story-production-review.md`；需要观众盲测时另读 `audience-scroll-simulation.md`。

不要展示未入选候选的详细推演，也不要用数量目标覆盖质量门槛。

## 成片结构预设

以下时间只规定职责，不要求机械等长：

| 时间 | 必须完成的职责 |
|---|---|
| 首帧–1.5 秒 | 可见的异常动作、危险、拒绝、破坏、损失或结果；静音也能看出有事发生 |
| 1.5–5 秒 | 明确谁在对谁做什么；形成一个具体追看问题 |
| 5–12 秒 | 观众至少看懂两人的关系与眼下冲突；允许用金句、旁白或大字幕直给 |
| 12–35 秒 | 形成第一次明确情绪转向；可以靠动作、对白、音乐、闪回或揭晓完成 |
| 35–55 秒 | 再形成一次期待、误判、心疼、生气或失望的转向，把情绪推向爆发 |
| 55–80 秒 | 完成爆发动作、对方从没看懂到看懂的完整反应，以及不可逆关系变化 |
| 最后 5–10 秒 | 只保留一个回应动作或余波，随后结束 |

## 情绪硬门

### 一个情绪爆发点

先用 5–15 秒写清人物为什么在这一刻痛、舍不得、释然或崩溃。动作、金句、哭喊、身份揭晓、文件、道具、旁白与音乐都可以参与；只要情绪变化首遍可懂且足够强，不因表达直给或 AI 味重判失败。

### 一句人话能复述

未读设定的人不需要理解职业制度或技术流程，也能说出“原来他一直……她最后……”。若梗概必须用“为了触发程序、根据规定、系统显示、资格只能”才能成立，不通过。

### 一个强钩子

前三至五秒必须形成具体追看问题。钩子不要求高级、自然或无 AI 味；大字、金句、哭喊、危险结果、冲突和答案前置都可以，只看是否让观众想继续。

### 至少两次情绪转向

从开场到爆发点，观众至少经历两次清楚变化，例如“好奇→生气→心软”或“期待→失望→崩溃”。如果只有结尾突然感动，前段情绪始终平直，不通过。

### 一个关系

只追一组关系问题。配角可以阻止、催促或见证一次，不得获得独立转变。

## 故事生产约束

以下项目决定故事能否形成低场景、可视觉化的生产骨架。除非用户本轮要求或项目锁定配置明确允许多场景，“一个主场景”与真实阻力、有价选择、情绪回报均为硬门；金句、揭晓和强音乐不能弥补硬门失败。轻微逻辑省略、跳切和表达风格只记录最低成本风险。

### 一个主场景

当下困境、选择和回报全部发生在同一故事现场。禁止“回家后才发现”“第二天补偿”“多年后重逢”。短回忆不能承担高潮。

### 一个真实阻力

人物把动机全部说清楚后，关系边界、对方已经作出的决定、错过的时机、必须真正放手的代价、时间、空间或唯一资源仍然存在。优先使用观众无需学习即可理解的生活阻力；少用职业制度和技术程序，不得把故意沉默当成阻力。

### 一个有价选择

角色必须在镜头里做出不可撤回的关系选择，并承担现实或关系后果。代价可以是时间、金钱、安全、名誉、位置、名额，也可以是真正放手、停止等待、失去关系独占或承认自己需要对方；但必须有动作和后果，流泪、拥抱、道歉和说真话本身不能替代选择。

### 一个情绪回报

第一次观看、不读长文字也能理解。回报首先靠人物动作、对方反应和空间关系完成，物件只作可选增强。回报后不得再次用台词复述主题。

### 钩子形式参考

从下列选择一种：

- **答案前置**：先给牺牲或结果，追看代价如何发生；
- **冲突谜面**：先让一句气话、指责或反问形成真实关系冲突；后段把其中的比喻义兑现为字面事实。它开场给的是问题，不是答案；
- **看似很坏**：可见动作让观众想看报应或改义；
- **危险倒计时**：不立即行动会出现明确后果；
- **反常动作**：观众能具体问“为什么正在这样做”。

纯标题、人物哭泣、电话弹窗、环境空镜和“后来才知道”不算钩子。

### 冲突谜面的附加检查

- 不看后文，前三秒是否仍是一次清楚的冲突，而不是孤立金句？
- 后段是否回收同一个词、动作或物件，并使其从比喻变成事实？
- 第一层答案揭晓后，是否立刻生成“代价是什么、为何没有做到、接下来如何选择”等更深问题？
- 75–95 秒项目只能借这一结构机制；不得因为参考三分钟案例而扩展完整前世线、战争线、遗物线和多年守候。

### 看似很坏的附加检查

- 区分“被动误判”和“策略性伪恶”。策略性伪恶是角色主动牺牲名誉、关系或安全，把自己置于不利位置；
- 写清作用链：`坏动作 → 旁观者或规则反应 → 必要程序 → 真目标暴露`；
- 坏动作必须实际完成拖延、证据保全、位置交换、公开见证或规则触发中的至少一项，不能只为拖到结尾再洗白；
- 检查直接说出真相是否会让故事消失；若会，记录为误会驱动。只要误会本身形成强钩子、持续情绪变化和有力揭晓，不自动淘汰；
- 75–95 秒只保留一个误判层和一个证据回看，不复制三分钟案例的报案、群体争吵、抓捕、回忆与家庭收尾全套结构。

## 解释消失测试

写出人物最早可以说清楚的一句话，然后判断：

> 这句话在开场说出后，真实阻力、当场选择和高潮动作是否仍然必须发生？

若主要剧情因此消失，故事硬门失败，不进入视频生产。可以保留为未通过草稿供用户讨论，但不得用强钩子、揭晓或煽情弥补真实阻力缺失。

## 可视化与 AI 生产约束

- 每 5–8 秒至少有一次人物动作、期待变化、空间后果或对方反应；
- 不为满足模板强塞核心物件；使用物件时，其状态变化必须自然服务人物动作；
- 画面能表达的事实不用旁白重复；
- 人物年龄、脸、发型、服装和左右站位保持稳定；
- 避免大规模群众、战争全景、复杂追车、多年龄角色和高难手部连续动作；
- 历史题材用近景旧物、局部动作和短回忆承载，不为场面感扩展第二现场；
- 情绪高潮必须给触发、期待、选择、对方反应和余波完整表演时间。

## 创作者预检

首次交付前只检查：

- 首帧和前三至五秒是否形成具体追看问题；
- 主要关系与当下困境是否首遍可懂；
- 说清楚后真实阻力是否仍然存在；
- 是否有当场完成的有价选择和猛烈回报；
- 爆发前是否至少有两次清楚的情绪变化；
- 核心动作能否视觉化并压入合理的视频单元。

预检只记录“符合／风险”和一句证据。它不能给出PASS、生产等级、代理留存、观众人口权重或正式放行决定，也不能触发后台自动重构。正式盲测交给未参与创作的独立子代理。
