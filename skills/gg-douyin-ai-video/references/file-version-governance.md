# 故事文件与版本治理

只在用户授权改稿、落文件、归档或维护项目真源时使用。诊断、评审和观众模拟不得暗中移动、改名或改写故事稿。

## 当前稿与旧稿

- 当前最佳稿始终使用稳定原文件名，不在当前文件名后追加`v2`、`v3`；
- 写入替代稿前，将旧当前稿归档为`<故事名>_废稿N_<淘汰原因>.md`，N递增且不覆盖；
- 仍可继续开发的不同方向使用`<故事名>_备选N_<方向>.md`，不标废稿；
- 归档稿首部记录状态、停止推进原因和归档日期，保留原内容与旧评审结论。

## 评审证据分离

- 正式评审：`<故事名>_生产评审_vN.md`；
- 观众盲测：`<故事名>_观众盲测_vN.md`；
- 评审文件注明故事路径、版本或哈希和评审时间；
- 评审文件不能冒充故事当前稿，旧版本结论不能放行新版本。

用户只要求评审时不归档源稿。只有用户授权改稿且实际生成替代版本，才归档旧当前稿并把稳定原名写成新稿。用户明确指定其他命名方式时，以用户要求为准。

## 完成回执

列出当前真源、归档文件、评审证据文件和未改动的相关文件。若删除任何材料，说明删除目标和可恢复来源。
