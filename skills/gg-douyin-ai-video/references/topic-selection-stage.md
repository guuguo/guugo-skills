# 高流量方向发散与选题阶段

本阶段发生在完整故事创作之前。目标是先找到能承载强情绪爆发的关系时刻，再结合当前可核验的热度信号和项目生产条件，给用户一组值得继续开发的方向；不使用未经校准的百分制或固定分数线筛选。

## 进入条件

- 用户说“先发散”“给几个候选”“题材你选”；
- 用户只给红军、反拐、父女等宽泛母题；
- 用户要求按当前高流量、高热度或爆款方向选题；
- 用户要求再来一批并避免换皮。

用户明确说“直接写”“你选最好的”或已经选定候选编号时，可以跳过等待，但仍须完成候选比较并保留推荐理由。

## 热度证据

进入C01自主选方向时，默认检索当前可核验信息并记录平台、来源、采集日期和可见指标；用户明确要求离线发散或只按常青关系题材时可以不联网，但必须标记“当前热度未核验”。证据优先级：

1. 用户账号的真实留存、互动结构、评论主题和粉丝画像；
2. 抖音作品页、热榜、话题页和平台公开趋势工具；
3. 巨量引擎、抖音或字节跳动发布的趋势与行业报告；
4. 权威机构近期创作计划和重点主题；
5. 其他平台榜单、媒体报道和公开案例，只作交叉验证；
6. 长期关系共鸣与创作经验，只标为工作假设。

找不到可靠当期数据时写“当前热度未核验”。官方计划、备案数量和单条爆款都不能直接证明当前抖音流量。

每个候选分开写：事实、推断和本项目决定。禁止“平台一定推”“最近必爆”“观众都爱看”。

## 候选池与硬筛选

默认内部发散不少于十二个`关系需要＋爆发动作＋对方反应＋余波`方向，再筛成四至六个展示：

- 至少覆盖三种题材母类；
- 同一种核心关系和开场钩子最多各两个；
- 不与近期故事重复核心物件、主场景和结尾动作；
- 必须能用人话复述核心关系、当下困境和情绪爆发；
- 必须有具体前三秒追看问题、真实阻力、有价选择和首遍可懂回报；
- 如果人物把话说清楚故事就消失，直接淘汰；
- 事实、安全和伦理风险无法处理，直接淘汰。

## 相对比较，不做总分

对通过硬筛选的方向按以下维度标记`强／中／弱／未知`，并给一句证据：

| 维度 | 判断问题 |
|---|---|
| 情绪爆发与关系投射 | 爆发是否猛烈，容易想到现实中的谁 |
| 首帧与前三秒钩子 | 是否立即形成具体追看问题 |
| 情绪起伏 | 爆发前是否至少有两次清楚变化 |
| 真实阻力与有价选择 | 说清楚后阻力是否仍在，选择是否有代价 |
| 当前热度证据 | 是否有带日期的平台、账号或权威信号 |
| 最低理解 | 谁和谁、发生什么、为何情绪变化是否首遍可懂 |
| AI生产风险 | 核心画面、动作和人物连续性的成本是否可控 |

排序采用成对比较：先淘汰硬门失败者，再比较爆发、钩子和情绪起伏；前三项接近时，才用当前证据和生产成本决定推荐顺序。不得把`强／中／弱`换算成隐藏分数。

```markdown
- 真实阻力：说清楚后仍存在什么

- 维度判断：爆发__；钩子__；起伏__；阻力与选择__；热度证据__；最低理解__；生产风险__

```

## 默认输出

按相对优先级给四至六张候选卡，并明确：最推荐、最稳生产、最大胆实验。每个排序必须有理由，不显示分数。

用户没有说“直接写”时，候选交付后停止，等待选择。用户选择后进入`story-creation-preset.md`；最终正式候选仍须经过`story-production-review.md`和需要时的`audience-scroll-simulation.md`。
