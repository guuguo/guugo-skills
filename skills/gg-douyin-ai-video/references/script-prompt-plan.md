# 脚本提示词方案

> 当前 C06/C07 入口已迁移到 `$ai-video-director-prompt`。本文件仅保留历史兼容，不再作为脚本或视频提示词生成的必读参考，也不得覆盖 `$ai-video-director-prompt` 的景别、运镜、守轴、表演链、切法和动作音效决策。

## 适用范围

当故事需要被写成可直接进入分镜、图生视频或多段生成后拼接的脚本时使用本方案。本文件是镜头、动作、表演、对白、声音和连续性的唯一真源；进入视频提示词阶段后，只允许通过`video-prompt-assets-and-runtime.md`添加资产绑定、模型格式和运行参数，不得另立镜头方案。

当前项目已有更具体的时长、画幅、模型或分幕规则时，以项目规则为准。没有额外规则时，每个视频生成单元优先保持`5–15秒`。

## 四种单位必须分开

- 成片总时长：整条视频最终长度。
- 视频生成单元：一次模型生成任务产出的一段独立视频文件，内部可以包含多个剪辑镜头。
- 剪辑镜头：一个生成单元内部实际发生的景别或视点切换。
- 静态视觉资产：角色图、场景图、START、END、KEYFRAME或REF。

不得把“一个视频生成单元”写成“只能有一个剪辑镜头”，也不得因同一场景内出现近景、中景、远景、反打、跳切或短闪回就机械拆成多个生成任务。

## 视频单元边界

默认先合并，再证明为什么必须拆。同一主要场景或同一连续时间线中的景别变化、正反打、视线切换、动作匹配、声音桥、状态揭示和短促回忆，优先放在同一个`5–15秒`视频单元内部。开场电话两端来回切换、人物看向危险物的反打、不到几秒的童年闪回，都不因画面地点变化自动成为独立视频。

只有当前动作胶囊已经结束，并出现以下一种变化时，才优先拆新单元：

- 进入新的主要场景，且不是同一事件中的短反打或瞬时插入；
- 核心动作明显改变，例如走路变成攀爬、寻找变成砸墙、地面移动变成高处悬挂；
- 人物身体关系或稳定状态明显改变，例如地面站立变成梯顶悬挂、独自行走变成背负他人；
- 一段完整回忆或独立支线本身足以形成约`5–15秒`视频，而不是`1–2秒`动作闪回；
- 当前单元超过模型时长上限，或动作负载无法在一次生成中稳定完成。

计划出的单元不足5秒时，默认并入前后最相邻的连续时间线，通过硬切、反打、跳切或声音桥放在单元内部。只有模型硬限制、独立可复用素材或用户明确要求，才保留不足5秒的独立生成任务；不得为了剪辑方便常态化创建`1–2秒`视频单元。

每个单元必须写清起始状态、连续动作、必要切镜和结束状态。结束状态应能直接成为下一单元的开场输入。

### 边界示例

- `母亲火中打电话 → 儿子街口接听 → 切回母亲说完告别`：同一通电话、同一连续时间线，合并为一个约5秒单元，三个画面是内部硬切。
- `梯顶抓空 → 闪回母亲扶自行车不到一秒 → 现实重新抓紧铁栏`：同一动作因果链，闪回作为动作匹配跳切留在单元内部。
- `儿子步行回家 → 冲进院子寻找办法 → 开始爬梯`：从地面移动、寻找工具到攀爬，核心动作和身体状态明显改变，可按约`5–15秒`胶囊拆分。

## 镜头语言

### 默认少切，但需要切时写明

未标注切镜的动作默认在同一机位或连续运镜中完成。以下切镜承担明确职责时必须写出名称和承接动作：

- **硬切**：危险升级、信息突然出现、空间或尺度形成对照；
- **视线反打**：从人物目光切到其看见的人或物；
- **动作匹配跳切**：用同一个转身、伸手、起身、背负或关门动作压缩中间过程；
- **遮挡转场**：人物身体、门、车辆、烟尘或强光遮满画面后进入下一状态；
- **声音桥切镜**：下一空间的声音先出现，再切到声源画面；
- **呼吸镜头**：高密度动作或情绪落点后的短暂停留，画面仍有呼吸、视线、手指、衣物或环境声变化。

不要为了显得专业而给每个动作安排切镜。一个连续动作能在同一机位完成时，明确写“单一连续镜头，不切”或直接保持连续描述。

### 每个单元必须闭合镜头与音轨

精简提示词只能删除重复身份、默认状态和生产元话，不能删除模型执行所需的导演与声音信息。每个视频单元必须让人能直接回答：

- 开始是什么景别，机位在什么位置，固定还是跟随；
- 内部切镜发生在哪里，切后是什么景别或角度；
- 人物和关键物件最后停在什么状态；
- 有没有背景音乐；没有时明确写`无背景音乐`，不能用空白代替；
- 当前空间持续存在什么环境声，哪些动作必须听见；
- 对白、电话录音、画外声等是否与动作声保持可辨认。

这些是输出不变量，不要求固定分栏。可以自然写进动作段落，并在结尾用一句音轨说明收束。没有必要运镜时写固定机位；没有内部切镜时保持单一连续镜头，不为了填字段增加切镜。

### 不写过细的剪辑时间线

脚本标题可以保留视频单元的整体时段与时长，但不把内部切镜拆成密集的逐秒表。只有台词同步、危险倒计时、音乐落点或动作顺序容易被误解时，才给内部段落粗粒度时间范围。精确时间轴留给视频提示词或剪辑阶段。

### 呼吸镜头必须仍在发生变化

呼吸镜头不是纯氛围空镜。可写：

- 人物没有马上说话，胸口起伏一次；
- 伸出的手停住，手指收紧或松开；
- 强光退去，只剩衣摆、白羽、雨刷或环境底声继续运动；
- 对方听完一句话后抬眼、咽一下或重新抓紧物件。

前三秒冷启动、危险仍在逼近或关键动作尚未兑现时，默认不插呼吸镜头。

### 克制推近、拉远和环绕

默认使用固定机位、跟随主体动作或明确切镜。缓慢推近、缓慢拉远和缓慢环绕不是通用“电影感”指令：

- 只有景别变化本身承担信息揭示、人物关系反转或动作落点时才使用；
- 同一视频已经通过切换中景、近景、特写或远景完成信息变化时，不再叠加缓慢推近；
- 多个视频拼接前横向检查运镜，不让相邻单元重复同一种缓慢运动；
- 能用人物走近、转身、遮挡、视线反打或动作匹配切完成的变化，不用缓慢推进代替。

例如“人物近景直接拉开为英雄远景，揭示他已被另一人横抱悬停”有明确揭示职责，可以保留；“双人中近景缓慢推近，让观众看清表情”没有新增信息，应改为固定机位和具体表演。

## 只写模型能生成或听见的内容

正文直接从场景、人物和动作开始，不写“首帧为”“本单元是”“本镜头用于”等生产元话。已有START、KEYFRAME或角色参考图时，由资产映射承担首帧构图和人物身份；正文只描述画面里正在发生什么。删除这些元话不授权删除景别、机位、运镜、切镜、音乐状态、环境声或动作声。只有模型必须区分具体起始帧与结束帧时，才在运行适配层使用START／END字段，不把字段名写成剧情句式。

保留：

- 景别、机位位置、高度、俯仰角和必要运镜；
- 人物站位、视线、嘴唇、眼睛、手指、肩背和身体动作；
- 物件位置、归属、形态和变化；
- 对白、口型对象、内心声、环境音与动作声；
- 光线、烟尘、雨水、衣摆、发丝、羽毛等动态变化；
- 入镜状态和出镜状态。

删除：

- 作者意图：`这里是为了表现他终于心软`；
- 观众效果：`让观众看清她空洞平静的表情`；
- 抽象心理：`他意识到命运已经改变`；
- 无法执行的评价：`镜头很高级、很感人、很有电影感`。

把解释翻译成可见动作：

```text
错误：播报期间不切镜，让观众看清豆包空洞平静的表情，以及程野持续震惊的反应。

正确：双人中近景固定机位。程野始终盯着豆包，双眼睁大，身体僵住；豆包不看他，眼神无焦点、面部没有表情变化，机械口型与播报同步。
```

## 对白与声音写法

脚本正文直接写人物和台词，不插入“首次建声”“声音锁定”“暂无参考音频”等工作流标签。角色参考图已经提供身份、年龄和外貌时，不在对白旁重复这些信息。人物名后的括号只写会明显改变本句声音或表演的特殊状态：

```text
母亲（被浓烟呛咳，呼吸短促）：“儿子。”
```

- 普通话、无明显地域口音、正常呼吸、日常放松和普通画内近声都属于默认值，不写。
- 当前状态只写会改变声音或动作的身体、环境或情绪事实，例如呛咳、哭过、受伤、剧烈喘息、隔着暴雨喊话、强忍哭腔。
- 没有异常状态时直接写`儿子：“咋了妈？我快到了。”`，不使用空括号，也不补默认声线描述。
- 只有缺少角色参考图且声音身份会产生歧义时，才补最少量必要声线信息；不把完整角色设定复制到台词旁。
- 普通画内对白默认由当前人物开口，不写“嘴唇同步”“声源：画内”等模型基础能力。
- 只有旁白、心声、电话声、画外声、广播、录音和系统声等容易混淆的声音，才明确标注声源；心声明确人物没有开口。
- 同一人物后续对白仍只补当下异常变化。例如：`儿子（剧烈喘息，嗓音嘶哑）：“妈……我到了。”`
- 正式音频的提取、验收和后续绑定属于视频运行适配层，不写进脚本对白。未通过验收的候选声音不得冒充正式参考音频。

脚本正文还应删除面向生产人员或节点系统的元说明，例如“本单元是一个5秒独立视频”“不拆节点”“进入LibTV前替换Node”。单元时长由标题表达，节点与素材规则写在运行适配文件或提交计划，不作为模型动作提示。

## 推荐脚本格式

```markdown
### video-01｜00:00–00:10｜场景｜动作胶囊

起始景别与机位。人物的连续动作、表情、视线、物件和环境变化。

需要时明确写：视线反打／硬切／动作匹配跳切／遮挡转场／呼吸镜头。未写切镜的部分保持连续。

对白或声音归属。结尾停在可见、可继承的身体与物件状态。
```

不要为固定格式重复剧情，也不要额外写“镜头目的”“观众感受”或制作说明。

## 自检

- 每个视频单元是否优先保持`5–15秒`且不超过当前模型上限；
- 是否仍存在只因一次切镜、反打或短闪回而产生的`1–2秒`微型单元；
- 视频单元和内部剪辑镜头是否没有混用；
- 同一主要场景或连续时间线是否优先合并，核心动作、主要场景或身体状态明显变化处是否正确拆单元；
- 必要的跳切、反打、遮挡转场和呼吸镜头是否明确；
- 不必要的切镜和逐秒微切是否已经删除；
- 缓慢推近、拉远或环绕是否有不可替代的揭示职责；
- 多段拼接后是否出现重复运镜模板；
- 是否只写可见可听内容，没有作者意图和观众效果；
- 正文是否直接从场景、人物和动作开始，没有“首帧为”“本单元是”等生产元话；
- 每个单元是否仍有起始景别与机位、必要切镜、动作落点、背景音乐状态、环境声和关键动作声；
- 对白括号是否只保留真正改变声音或表演的异常状态，没有重复参考图已提供的年龄、性别、外貌及默认普通话、正常呼吸；
- 普通画内对白是否删除了“嘴唇同步”等基础能力说明，旁白、心声、电话、画外声和录音是否仍明确区分；
- 正式音频绑定是否留在运行适配层，没有污染脚本正文；
- 脚本正文是否没有“不拆节点”“本单元是独立视频”等生产元说明；
- 上一单元的结束状态是否等于下一单元的开始状态；
- 对白、口型、内心声、物件归属和人物身体关系是否连续。
