# 逐镜提示词快查

选择顺序只有四步：本镜让观众看什么 -> 用什么景别 -> 镜头如何观察 -> 为什么在这里切。

## 五问

- 本镜唯一主任务是交代空间、人物关系、动作、情绪还是关键细节？
- 谁做了什么唯一主动作，动作完成的可见端点是什么？
- 观众能不能一眼看出谁在看谁、谁靠近谁、谁退开谁？
- 角色情绪是否已变成眼神、头部、肩颈、手部和停顿，而不是形容词？
- 下一次切镜带来了什么新信息、反应或节奏变化？答不出就不切。

## 景别

| 景别 | 主要作用 | 适合场景 | 慎用 |
| --- | --- | --- | --- |
| 大远景/远景 | 交代地点、规模、孤立感 | 换场、环境异变、人物进入 | 已知空间里的短对白会浪费时长 |
| 全景/双人全景 | 看清全身、走位和距离 | 追逐、肢体喜剧、多人调度 | 细微表情和口型不够清楚 |
| 中景/双人中景 | 同时看关系、手势和环境 | 对话建立、击掌、递物、争执 | 情绪爆点可能不够近 |
| 中近景 | 同时保留表情与上半身动作 | 短剧对白、关系变化、克制反应 | 大幅走位容易出框 |
| 近景 | 放大眼神、口型和即时反应 | 反转、犹豫、心动、说关键句 | 连续滥用会让空间消失、情绪疲劳 |
| 特写/大特写/插入 | 锁住眼睛、手、屏幕或道具状态 | 线索、按键、道具转移、强反应 | 只在细节会改变理解时使用 |

过肩镜头不是单纯景别，它把“谁在看谁”放进画面；主观镜头让观众暂时共享角色所见。双人关系戏优先用双人中景建立关系，再按情绪需要进入过肩或近景。

## 角度与视点

| 角度/视点 | 作用 | 使用场景 |
| --- | --- | --- |
| 平视 | 中性、自然、便于读表演 | 常规对白和关系戏的默认选择 |
| 轻俯拍 | 看清桌面、动作路径，或让人物显得弱 | 道具操作、窘迫、被压制 |
| 轻仰拍 | 放大力量、压迫或决心 | 权力变化、人物做出决定 |
| 侧面双人 | 看清距离、朝向和动作接触 | 击掌、递物、靠近、错身 |
| 肩后过肩 | 进入对话并保留关系轴 | 追问、试探、观察对方反应 |
| 荷兰角 | 制造失衡和异常 | 明确的眩晕、故障、心理失衡；少用 |

## 运镜与呼吸

| 方式 | 画面效果 | 适用场景 |
| --- | --- | --- |
| 固定镜头 | 空间稳定，动作和喜剧节拍更清楚 | 双人互动、特效发生、冷幽默、重要走位 |
| 轻微手持呼吸感 | 主体稳定，画面只有很轻的自然微动 | 贴身观察、生活感、轻微不安；不是明显摇晃 |
| 固定镜头留呼吸 | 动作或对白结束后不切，人物保持半拍，环境声继续 | 心动、尴尬、余味、笑点落地 |
| 缓慢推近 | 收窄注意力，逐步增强亲密或压力 | 意识到真相、关键句、情绪升高 |
| 缓慢拉远 | 把人物重新放回环境，产生疏离或余波 | 决裂、孤独、事件结束后的回落 |
| 横摇/竖摇 | 逐步揭示信息或跟随同一空间动作 | 从人物摇到道具、人物入场、视线所指 |
| 跟拍/横移 | 保持人物运动连续，展示关系变化 | 行走对白、追赶、两人并肩或错位 |
| 快速甩镜 | 突然转移注意力并制造冲击 | 喜剧反打、突发闯入、动作爆点；单幕少量使用 |
| 焦点转移 | 不切镜，把注意力从前景交给背景或反向 | 暗示偷听者、先看道具再看人、信息揭示 |

“呼吸感”必须二选一写清：镜头轻微自然微动，或固定镜头在动作后停留半拍。不要只写“镜头有呼吸感”。

## 切法与节奏

| 切法 | 是什么 | 适合场景 |
| --- | --- | --- |
| 硬切/直接切 | 前镜立即换成后镜，无转场特效 | 同场对话、动作与反应、绝大多数短视频连接；默认选择 |
| 动作切 | 在抬手、转头、起身等动作进行中切换景别 | 隐藏切点、加强击掌/递物/转身等动作冲击 |
| 反应切 | 事件或台词落下后切到听者 | 笑点、暧昧、误会、关系变化；别只拍说话者 |
| 快切 | 多个短镜连续硬切，整体节奏明显加速 | 前三秒钩子、混乱、搜寻、准备过程、高潮；不是每条短视频默认风格 |
| 跳切 | 同主体同机位明显跳过一段时间或动作 | 压缩重复过程、喜剧、省略等待；不要用于需要连续的肢体互动 |
| 匹配切 | 用相似动作、构图或声音连接两镜 | 跨时间/地点但要保持流动或形成隐喻 |
| 声音先行（J-cut） | 下一镜声音先进入，画面稍后切换 | 门外来声、下一人抢话、提前引出新空间 |
| 声音延续（L-cut） | 前镜对白或音效延续到下一画面 | 保留情绪余波、边听边看反应、柔化硬切 |
| 淡出/叠化 | 可见地过渡时间、记忆或段落 | 明确跨时、回忆、结尾；短时单幕慎用 |

快切是一种节奏，不是一种单独转场。写法要给出连续短镜、各自的新信息和共同节奏；硬切则要写成“画面直接切换，无叠化或花式转场”。

切镜优先级：情绪落点 -> 新剧情信息/动作 -> 节奏 -> 视线与空间连续。一次生成里能用较少镜头讲清就不加镜；尤其不要在同一小镜头叠加复杂运镜、复杂走位、特效和长对白。

## 常用节奏组合

- 日常双人戏：双人中景建立关系 -> 动作切到中近景 -> 反应近景 -> 过肩或双人镜留半拍回稳。
- 喜剧：固定中景建立正常状态 -> 突发动作硬切特写 -> 反应近景停半拍，让笑点落地。
- 紧张/故障：关键细节特写开场 -> 2至3个动作/反应快切 -> 缓慢推近人物 -> 固定镜头留余波。
- 揭示：先遮住答案 -> 横摇、焦点转移或动作切揭示 -> 反应近景 -> 拉远看清后果。

## 时长

- 1.5-2.0 秒：道具或反应特写，无对白快速动作。
- 2.0-3.0 秒：短动作加一句短对白。
- 3.0-5.0 秒：双人互动、身体调度、带停顿的反应。
- 5 秒以上：连续动作、复杂特效、走位、沉默余波；写明“单一连续镜头，不切”。

## 守轴句式

```text
角色A在画面左侧，视线朝右；角色B在画面右侧，视线朝左。后续反打、过肩和特写保持同一人物关系轴，不交换左右位置。
```

```text
角色A肩后过肩近景，角色A左侧前景虚化，角色B在右侧清晰，视线朝左守轴。
```

## 表演翻译

- 惊讶：先停手，抬眼看声源，肩膀微后缩，半拍后开口。
- 尴尬：避开视线，手指摸到道具又放下，吸气后小声说话。
- 心动：先看对方动作，再迅速看向别处，嘴角压住，手上慢半拍。
- 机器人式克制：目光移向目标，头部只轻微偏转，眉眼不变；嘴唇小幅开合，说完闭口回到原目标。
- 普通年轻人嘴硬：身体先诚实靠近或停住，台词才找补；说完低头看道具或屏幕。

## 声音

动作声跟动作绑定：椅轮、手柄、翻页、杯盖、衣料摩擦、拍肩、击掌、脚步、门锁、能量启动、扫描提示、倒计时、环境底噪。

每个单元末尾写清：角色声音引用、口型幅度、音乐进入/停止、环境声，以及“无字幕、水印或旁白”等限制。

## 短例

```text
**Shot_08_第一次击掌**
时长/画幅/用途：10秒，16:9，单个视频生成单元。
**Element_EP02_小智卧室** 清晨。大镜头包含4个连续小镜头：
- 镜头1（0-2.0s）：游戏桌侧面双人中景，平视固定机位。小智**Element_小智睡衣版本**在画面左侧，视线朝右；豆包**Element_豆包**在画面右侧，视线朝左，保持关系轴。两人仍站在上一段的位置；窗外住宅楼和卧室灯光先恢复供电，银白能源线随即开始收回围巾核心。小智先看恢复的电视，再转头看向豆包，眉毛扬起。
- 镜头2（2.0-4.2s）：沿小智转头动作硬切至双人中近景，画面直接切换，无转场特效。小智朝右举起手掌：“击掌啊，庆祝！”豆包身体不动，目光先落到他的掌心，停顿半拍，再抬起右手。
- 镜头3（4.2-6.2s）：沿豆包抬手动作切至两人上半身与手掌同框。豆包和小智清脆击掌；复电过程已经结束，不再出现额外强光或能量爆发。小智肩膀随击掌轻轻弹起，豆包面部保持稳定，只在听见击掌声后眨眼一次。她看向自己的手掌，轻声说：“已记录。”（音效：清脆击掌声、能源线轻微回收声）
- 镜头4（6.2-10.0s）：击掌声尾延续，硬切至小智肩后过肩近景；小智左侧前景虚化，豆包在右侧清晰，视线朝左守轴。小智问：“这也要记录？”豆包的目光从掌心移到小智眼睛，说：“下次主人高兴时，我就知道该怎么做了。”她不笑，嘴唇小幅开合；小智停顿半拍，嘴角自然扬起。对白结束后固定镜头再停留半拍，环境底声继续，让反应自然落地。
声音与限制：豆包对白音色参考 `Element_豆包声音`，小智对白参考 `Element_小智声音`。温和电子底乐压在对白下；保留复电声、能源线回收声与击掌声；无字幕、水印或旁白。
镜末状态：两人仍在游戏桌旁，豆包没有微笑，右手刚放下，mini 小翼和银白能源线完全收回；小智看着她笑意未收。
```

短例只示范方法，不是剧情模板。
