# AI 视频导演提示词

本技能只做一件事：把“故事说明”变成“摄像机和演员都能执行的逐镜提示词”。

它解决五个常见失败：景别和运镜没有叙事理由、镜头吞动作、人物左右乱跳、表情只有抽象词、画面没有可听见的动作。

先问“观众此刻必须看清什么”：空间、关系、动作、情绪还是细节。再选景别和运镜，最后决定在哪里切；没有新信息、新动作冲击或新情绪反应，就不切。

## 先锁住

能从上下文或项目文件确定时直接采用；缺失会改变剧情或生产边界时再问。

- 真源：脚本、分镜、故事片段或指定视频单元。
- 规格：画幅、总时长、模型限制、是否同一生成单元内切镜。
- 资产：角色、场景、道具、声音、屏幕等 `Element_*` 名称。
- 连续性：上一镜末状态、本镜开场状态、本镜结束状态。
- 禁止项：不能改剧情/对白/服装/镜末状态，是否无字幕、水印或旁白。

## 四个钉子

1. 镜头语言：每个小镜头写清时长、景别、角度、稳定/运动方式、主动作和切法。远景看空间，中景看关系与动作，近景看情绪，特写看关键细节；运镜必须有叙事动机。硬切是默认连接，快切只用于明显加速，呼吸感必须落实为轻微手持微动或动作后的停留，不写空泛形容词。
2. 关系守轴：双人戏第一镜锁左右和视线方向；反打、过肩、特写都保持同一银幕方向，除非人物调度明确换位。
3. 表演链：把“惊讶、尴尬、心动、冷静”翻译成可见动作：刺激 -> 眼神/头部/肩颈/手部 -> 台词 -> 回稳。
4. 动作音效：每个关键动作配对应声音；最后统一写清角色声线、口型、音乐、环境声、字幕/水印/旁白限制。

短视频不等于一直快切。每新增一个切镜都应承担新信息、反应或节奏转折；同一镜不要同时塞复杂运镜、复杂走位、特效和长对白。

## 输出模板

```text
**Shot_编号_标题**
时长/画幅/用途：...
承接：上一镜末...
**Element_场景** 时间与状态。大镜头包含N个连续小镜头：
- 镜头1（0-2.0s）：景别，角度，机位/运动。角色A**Element_角色A**在画面左侧，视线朝右；角色B**Element_角色B**在画面右侧，视线朝左，保持关系轴。可见动作与对白。（音效：...）
- 镜头2（2.0-4.5s）：[硬切/动作切/声音先行/连续不切]至景别，角度，机位/运动。可见动作与对白；写清镜末切镜动力。（音效：...）
声音与限制：...
镜末状态：...
```

项目已有固定字段或平台模板时保留原结构，只把上述导演信息落进对应字段。

## 不做

- 不借“优化提示词”重写故事、替换对白或改变镜末状态，除非用户明确要求。
- 不把内部切镜拆成多个生成任务；一次模型调用仍是一个视频生成单元。
- 不把参考案例里的“12镜、30秒、每镜2.5秒、环移镜头”当通用规则。
- 不上传、不写 Flova/LibTV、不生成、不重试、不发布媒体，除非用户另行明确授权。

需要选择景别、角度、运镜、呼吸镜头、快切/硬切等剪辑方式，或查看短例时，读取 [references/shot-language-guide.md](references/shot-language-guide.md)。
