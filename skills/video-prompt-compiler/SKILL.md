# 通用视频提示词与多平台适配编译器

本技能负责把已锁定的剧情脚本、分镜设计表、角色大脸特写与配音资产，编译为统一的单集《视频生成清单.md》，并生成对应的小云雀、即梦与 LibTV 平台适配方案。

> [!CAUTION]
> ### 🛑 额度与资金消耗硬门禁 (CRITICAL REDLINE)
> **真正的生成触发一定要人工确认，会真实消耗钱！**
> - 本技能的核心职责是**编译结构化提示词、组织引用资产与产出提交清单**，供用户审核与排查。
> - **严禁在未经用户在当前回合明确授权的情况下自动触发真实生成**（包括 `pippit-tool-cli generate-video`、即梦调度器入队、LibTV 跑批等）。
> - 任何涉及消耗 Credits / 额度 / 资金的提交动作，必须明确告知预估消耗与模型参数，并经由人工最终确认后方可执行。

---

## 核心输入与资产发现

在为目标单集执行编译前，按以下顺序发现工程输入：

1. **单集分镜与脚本**：
   - 分镜真源：`<系列>/剧集/<单集>/分镜.md`（包含幕切分、时间轴、六宫格描述）
   - 脚本真源：`<系列>/剧集/<单集>/脚本.md` 或 `<系列>/脚本/<单集>*.md`
2. **视觉与听觉资产**：
   - **分镜图**：`<系列>/资产/已选分镜/epXX-s*.png`
   - **角色锁脸图**：优先使用 `<系列>/资产/角色/*-大脸特写.png`（大主脸规范）；未提供时使用正式角色卡（若项目规定单一角色卡规范，则遵循项目特定规范）
   - **声音样本**：`<系列>/资产/声音/*.mp3`；若文件夹为空，自动生成待补充标记并在清单中提供明确占位
3. **项目画布与编译器配置（统一配置真源）**：
   - 读取 `<系列>/画布配置.json`（或独立的 `<系列>/编译器配置.json`）：
     - 取得小云雀专属画布 ID（`canvas_id`）；
     - 读取 `compiler_config` 专属生成参数（指定模型、比例、各平台分辨率等）。若未配置，则降级使用技能全局默认值。
   - **参数继承优先级**：`单集明确要求 > 项目专属配置 (compiler_config) > 技能全局默认值`。

---

## 项目专属编译配置协议 (`compiler_config`)

为杜绝每个项目因模型、分辨率、画幅差异导致多处维护或重复编写文档，所有项目统一在 `<系列>/画布配置.json` 根节点内声明 `compiler_config`：

```json
{
  "project_name": "系列名称",
  "compiler_config": {
    "default_model": "seedance2.0fast",
    "ratio": "9:16",
    "duration_per_scene": 15,
    "platforms": {
      "dreamina": {
        "model_version": "seedance2.0fast",
        "video_resolution": "720p",
        "ratio": "9:16",
        "duration": 15
      },
      "xyq": {
        "model": "Seedance_2.0_fast",
        "resolution": "480p",
        "ratio": "9:16",
        "duration": 15
      }
    }
  },
  "canvases": [...]
}
```

> [!TIP]
> **极简配置原则**：当用户要求“配置某项目的专属模型、画幅或平台分辨率”时，**只需在当前系列的 `<系列>/画布配置.json` 中配置 `compiler_config` 即可**。Agent 编译该系列任何单集时必须自动读取并生效，严禁四处改写无关代码或建立重复文档。

## 统一产物格式规范：《视频生成清单.md》

编译输出文件必须写入：`<系列>/剧集/<单集>/视频生成清单.md`。结构包含四大模块：

### 1. 基础元数据与参数
```markdown
# 《剧集名称》第X集《单集标题》视频生成清单

- 画幅比例：9:16 竖屏（继承项目配置）
- 默认模型：Seedance_2.0_fast（小云雀） / seedance2.0fast（即梦）（继承项目配置）
- 基准时长：15秒/幕（全集共 6 幕，90秒）
- 目标分辨率：即梦 720p / 小云雀 480p（继承项目配置）
- 项目对应画布：`<canvas_id>`（画布名称：`xxx`）
```

### 2. 全局资产引用索引（Asset Reference Index）
```markdown
## 全局资产映射表

- @图片1 = 分镜图: `<系列>/资产/已选分镜/epXX-s01.png`
- @图片2 = 沈知野锁脸卡: `<系列>/资产/角色/沈知野-大脸特写.png`
- @图片3 = 林屿锁脸卡: `<系列>/资产/角色/林屿-大脸特写.png`
- @音频1 = 沈知野声音: `<系列>/资产/声音/沈知野.mp3`（或待补充）
- @音频2 = 林屿声音: `<系列>/资产/声音/林屿.mp3`（或待补充）
```

### 3. 逐幕通用提示词方案（Per-Scene Universal Prompt）
每一幕以**单集脚本真源**为基准，保持原著生活流剧情的细腻呼吸感与对白张力，**由 Agent 根据剧情、分镜与角色音频严格编译，严禁通过代码机械死板拼接**：

- **核心结构**：
  ```text
  按照分镜图 @分镜图 生成视频，no music. no subtitle。<单集脚本中对应幕的生活流正文：正文中角色登场/动作处 at 角色卡，对白前引号内 at 对应声音>
  ```
- **关键规范**：
  1. **脚本即真源**：直接继承剧本中打磨好的生活流段落、对白停顿与神态反应，由 Agent 遵循剧情生成，不靠后端代码机械拼凑；
  2. **前缀引导（统一 @ 语义标签与空格隔离）**：开头统一为 `按照分镜图 @分镜图 生成视频，no music. no subtitle。`。**`@分镜图` 前后严格保留空格**，严禁与中文字符紧贴，彻底废弃底层的机器标记 `[image]`；分镜图后面只需 at 分镜图自身（`@分镜图`），严禁在开头前后重复两次或冗余堆砌角色名；
  3. **硬门禁控制**：`no music. no subtitle。` 严格消除视频模型随机幻觉硬字幕与杂音；
  4. **角色卡（视觉形象）引用**：在正文中**第一次提到角色出场或进行关键动作时**，自然内嵌角色卡（例如 `林予安 @林予安 肩上披着... 坐在身边的顾承砚 @顾承砚 ...`，前后严格保留空格）；若当前幕有大脸特写、局部神态特写或换装卡，在对应特写动作描写处 at 对应特写卡（如 `@顾承砚-家居服` 或 `@顾承砚-特写`）；
  5. **声音（音频）精确绑定（对白引号插槽）**：讲话的时候，**在对白双引号内部的第一个双引号紧接着后面带上 `@对应声音` 并紧跟一个空格与台词隔开**（例如：`顾承砚低声问：“@音频1 还疼？” 林予安低声坦承：“@音频2 ……疼。”`）；
  6. **场景与道具首次出场引用**：场景环境与关键道具首次在脚本中用到时带上 `@场景名` / `@道具名`（例如 `@顾总座驾-劳斯莱斯`），自动触发资产关联与画布小胶囊索引。

### 4. 平台适配层专区 (Platform Adapters - 可选衍生视图)

> [!TIP]
> **💡 衍生层自动推导原则**：小云雀 CLI、即梦 CLI 等各平台适配脚本属于**由《通用视听提示词》和《全局资产映射表》自动编译推导的衍生视图**。**在单集日常维护编写时，清单中完全不必手动逐幕手写这些重复代码块**；XYQ Studio 编译器与 Web 工作台在入库与展示时均会自动根据通用提示词与绑定资产推导生成，杜绝维护脑裂与多头同步成本。

#### 小云雀适配 (XYQ)
- **直接生成 CLI 指令**：
  在小云雀 CLI 命令中，提示词内的分镜图及登场角色、场景、道具必须严格按 `--image` 参数顺序映射为 `@图片1`、`@图片2`、`@图片3` 等，对白中的声音映射为 `@音频1`、`@音频2`，**开头必须保留空格写作 `@图片1 按照分镜图 @图片1 生成视频`**：
  ```bash
  pippit-tool-cli generate-video \
    --prompt "@图片1 按照分镜图 @图片1 生成视频，no music. no subtitle。角色A @图片2 走向茶几，坐在沙发上的角色B @图片3 转头问：“@音频2 怎么了？”角色A（@音频1）：“没事。”" \
    --model Seedance_2.0_mini --duration 15 --ratio 9:16 --resolution 720p \
    --image "/绝对路径/epXX-s01.png" \
    --image "/绝对路径/角色A-大脸特写.png" \
    --image "/绝对路径/角色B-大脸特写.png" \
    --audio "/绝对路径/角色A.mp3" \
    --audio "/绝对路径/角色B.mp3"
  ```
- **画布编排节点**：列出目标画布 ID、节点类型 (`video_generation`) 及对应的 `prompt_mutation.json` 结构。

#### 即梦适配 (Dreamina)
- **官方即梦 CLI 指令 (`multimodal2video` 全能参考模式)**：
  > [!IMPORTANT]
  > 即梦多模态模型底层仅按参数输入顺序感知 `@图片1`、`@图片2`、`@图片3` 与 `@音频1`、`@音频2`，无法识别中文自定义语义标签。因此平台适配 CLI 中的 `--prompt` 必须由编译器将通用提示词中的高阶语义标签转换映射为底层参数序号，**开头必须保留空格写作 `@图片1 按照分镜图 @图片1 生成视频`**，且各 `@` 序号标记与中文字符严格空格隔离：
  ```bash
  dreamina multimodal2video \
    --prompt "@图片1 按照分镜图 @图片1 生成视频，no music. no subtitle。角色A @图片2 走向茶几，坐在沙发上的角色B @图片3 转头问：“@音频2 怎么了？”角色A（@音频1）：“没事。”" \
    --model_version seedance2.0mini \
    --duration 15 \
    --ratio 9:16 \
    --video_resolution 720p \
    --image "/绝对路径/epXX-s01.png" \
    --image "/绝对路径/角色A-大脸特写.png" \
    --image "/绝对路径/角色B-大脸特写.png" \
    --audio "/绝对路径/角色A.mp3" \
    --audio "/绝对路径/角色B.mp3"
  ```
- **即梦调度器 (dreamina-scheduler MCP)**：标注双车道调度入队参数（`seedance2.0` 主车道 / `seedance2.0fast` 快车道）、并发控制与入队脚本。

#### LibTV 适配 (LibTV)
- 遵守 LibTV 额度硬门禁，生成适合网页端手动粘贴的纯提示词段落与节点插槽拖拽指引。

## 编译器自检与排查规则

在生成清单文件并落盘后，必须执行自检：
1. **分镜图检查**：检查各幕对应的 `@图片1` 文件在本地磁盘是否存在。
2. **角色图检查**：检查主角锁脸图是否存在，避免使用全身图代替大主脸。
3. **声音检查**：若声音文件不存在，在清单中明确标注 `(声音样本缺失，待补充)`，并在自检部分列出排查告警。
4. **触发 Web 工作台主动注册同步**：
   - **主动注册制原则**：Web 工作台只展示 SQLite 数据库中明确注册的项目与单集，严禁全局盲目扫描工作区其他无关工程。
   - **注册命令**：完成单集《视频生成清单.md》编译并落盘后，主动执行命令将该集录入 SQLite 数据库：
     ```bash
     python3 tools/xyq_studio/crawler.py register --project "<系列名称>" --episode "<单集编号>"
     ```
     （例如：`python3 tools/xyq_studio/crawler.py register --project "你家的船，是我在看" --episode "ep04"`）
   - **数据库安全刷新**：日常刷新使用 `python3 tools/xyq_studio/crawler.py refresh`，该命令仅刷新库中已存在的项目与单集，绝不导入外部未注册工程。
