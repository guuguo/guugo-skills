# 内容与受众分类

完整内容分析默认执行。分类对象是“该视频可能吸引哪些观看人群”，不是从演员外貌推断观众身份，也不是无数据的真实用户画像。先完成视听观察，再判断定位；分类引用 observations 中的观察 ID 和对应时间范围。

## 分类维度

| 层次 | 内容 | 判定依据 |
| --- | --- | --- |
| 内容形态 | 真人短剧、二维漫剧、动态漫、三维动画、解说、知识讲解、生活记录等 | 实际画面、叙述与剪辑方式，多标签可并存 |
| 题材与关系 | 都市、乡土、职场、悬疑、恋爱、家庭、成长、友情等 | 主事件和持续互动，不只看标题或某个道具 |
| 叙事与观感 | 生活流、强反转、轻喜剧、克制暧昧、冲突爽感、治愈等 | 回合、节奏、视听表达和情绪变化 |
| 核心与次级受众 | 最直接获得满足的人群，以及能被次要吸引点覆盖的人群 | 用兴趣/需求描述，如“偏好日常互动与缓慢关系推进的观众” |
| 兴趣与情绪需求 | 人物关系、推理、知识获取、轻松娱乐、陪伴、被理解、能力认可等 | 视频实际提供的观看回报及其证据 |
| 年龄/人生阶段 | 少儿、青少年、成人，或学生、职场、育儿等相关经验 | 内容理解门槛和议题；没有依据可为空，不臆造精确年龄段 |
| 观看门槛与场景 | 独立可看/依赖前集、是否依赖声音或字幕、适合快速浏览/连续追剧 | 信息依赖和实际表达；场景属于使用推断 |
| 定位与不适配 | 有依据时写男性向/女性向/不限性别等内容定位；不适配的兴趣偏好与原因 | 定位是内容假设；角色性别、配对或画风不能单独证明观众性别、性取向或占比 |

先判断核心回报，再形成受众分类。词表标签与自由解释并存，多标签不强迫互斥。生活流、爽剧等类型不代表作品质量；受众适配与艺术/制作评价分开。

## 保存结构

`observations.json` 增加：

- `content_profile`：`form[]`、`genre[]`、`relationship[]`、`tone[]`；每个标签项为 `{label, rationale, observation_ids}`。
- `audience`：`status`（inferred/unknown）、`scope`（实际分析的视频/片段范围）、`core[]`、`secondary[]`、`interests[]`、`emotional_needs[]`、`age_life_stage[]`、`viewing_context[]`、`positioning[]`、`mismatches[]`、`limitations[]`。
- 每个受众数组项为 `{label, rationale, observation_ids}`；`mismatches` 的 rationale 解释何种需求与本片不符。缺乏依据的维度保留空数组，并在 limitations 解释。不得填充“置信度 95%”或编观众占比。

观察 ID 引用本证据包的 observations；其中的帧号、ASR segment 与时间定位负责回查原片。分析只有片段时 scope 写片段，不上推为整部作品受众。

如果用户提供真实平台观众数据，另存 `audience_metrics`：来源、采集日期、统计范围、指标与数值。不要覆盖上面的内容适配推断；对比二者一致与不一致之处，不将评论样本当总体比例。

## 面向用户的默认交付

在视频内容分析后追加简短分类表：内容类型、核心受众、次级受众、吸引点/情绪需求、观看门槛、不适配偏好。每项给出具体画面或对白依据和时间码。年龄、性别定位缺证据就写“暂不判断”，不机械填满所有维度。

只有 ASR 或抽帧产物、尚未观察时，不生成貌似完成的分类。窄任务无需额外全片理解，可记录 `audience.status=unknown` 并解释覆盖不足。

## 入库传递

gg-drama-library 将完整 `content_profile` 与 `audience` 保存到单集记录，同时保留 `evidence_path`；观察 ID 仍以该证据包为命名空间。作品级汇总注明实际覆盖集数与分歧，不按单集替整剧下结论。桥段按该段的实际回报重新判断受众，可与作品定位不同。

桥段 `audience` 保留分组及解释；`tags.audience` 只写有证据支持的受众短标签，用于召回。原片受众与当前创作项目的目标受众分开：检索时比较二者，不能直接继承为改造后作品的真实画像。
