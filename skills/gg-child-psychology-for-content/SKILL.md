# 儿童心理学内容创作指南

## 核心原则

儿童不是"缩小版的成人"。他们的注意、记忆、语言、因果判断、情绪调节、道德理解和关系需要，都处在发展中。面向儿童的内容创作，必须先匹配儿童的发展阶段，再考虑趣味、教育目标和传播效率。

本技能默认服务内容创作和教育设计，不用于诊断儿童心理问题。遇到创伤、发育迟缓、严重焦虑、长期攻击行为、自伤或家庭风险，只能给出温和的支持建议，并提示寻求儿科、儿童心理、临床心理或学校专业人员帮助。

### 2. 学习后的底层判断

- **发展是全人系统**：认知、语言、情绪、社会性、身体动作和自我调节会相互影响。不要只做"知识点内容"，忽视情绪安全和身体经验。
- **年龄段是起点，不是判决书**：同龄儿童差异很大。先按年龄给默认边界，再按目标儿童的语言、经验、文化、家庭和兴趣调整。
- **儿童通过主动建构学习**：看、摸、试、说、假装、犯错、修正，比被动听讲更有效。
- **关系先于教育**：安全依恋、稳定回应和情绪共调节，是儿童探索世界的底座。
- **情境塑造发展**：家庭、同伴、幼儿园/学校、社区、平台算法、文化价值观都会影响儿童行为。不要把儿童问题简单归因成"孩子不乖"。
- **媒介不是中性容器**：短视频、游戏、动画的节奏、声音、互动方式和循环机制都会塑造注意、情绪和行为。
- **安全不等于爱看**：儿童心理学先给底线和适龄边界，但好作品还要有儿童动机、角色魅力、重复快感、幽默、参与感和可模仿性。

## 二、年龄段发展地图

| 年龄 | 发展重点 | 内容适配 | 常见误区 |
|------|----------|----------|----------|
| 0-2岁 | 感觉运动、依恋、安全感、共同注意、客体永久性萌芽 | 面向照护者共同使用；高对比、真实物体、简单动作、重复儿歌、亲子互动提示 | 把屏幕当早教老师；复杂剧情；突然惊吓；快速切换 |
| 2-3岁 | 语言爆发、自主感、模仿、简单假装游戏、秩序敏感 | "我自己来"、选择题、生活自理、固定流程、可预测结果 | 过度代劳；用羞耻控制；要求长时间安静理解抽象规则 |
| 3-6岁 | 前运算思维、象征游戏、自我中心视角、主动感、情绪命名 | 具象角色、线性故事、重复结构、尝试-犯错-再尝试、清晰表情和因果 | 闪回/多线叙事；抽象说教；抛弃威胁；否定哭和害怕 |
| 6-8岁 | 具体逻辑萌芽、规则意识、公平感、合作、勤奋感 | 简单推理、步骤化任务、努力带来进步、合作解决问题 | "别人家孩子"比较；只夸聪明；任务难度跳太快 |
| 8-12岁 | 具体运算成熟、分类/序列/守恒、同伴关系、能力感 | 冒险解谜、科学实验、团队分工、策略和后果、道德两难的具体情境 | 过早用成人式讽刺；把失败等同于能力差 |
| 12岁+ | 抽象推理、身份探索、价值观、同伴归属、独立性 | 多视角叙事、身份选择、复杂情绪、假设推理、开放结局 | 单一成功标准；刻板标签；居高临下的说教 |

## 三、核心理论到内容决策

### 1. 皮亚杰：认知复杂度的边界

皮亚杰提醒创作者：儿童不是先听懂成人解释，再照着做；他们通过动作、感知、图式、同化和顺应来建构理解。

| 阶段 | 年龄 | 核心特征 | 内容设计 |
|------|------|----------|----------|
| 感觉运动期 | 0-2岁 | 通过动作和感官认识世界，逐步形成客体永久性 | 用真实动作、重复结果、躲猫猫、拿起-放下、出现-消失；不要依赖情节理解 |
| 前运算期 | 2-7岁 | 语言和象征能力增强，但守恒、视角转换、复杂因果仍不成熟 | 画面具象、拟人可读、故事线性；每个变化要有可见原因 |
| 具体运算期 | 7-11岁 | 能处理具体逻辑、分类、序列、守恒和规则 | 可以加入解谜、实验、规则推理、因果链，但要落在可见事件上 |
| 形式运算期 | 11岁+ | 抽象、假设和演绎推理发展 | 可以使用隐喻、反讽、多视角和价值冲突 |

**前运算期硬规则**

- 不用闪回、平行叙事和复杂时间跳跃。
- 慎用突然变形。若角色或物体改变，要给出过渡、原因和结果。
- 用"重复结构 + 渐进变化"：例如遇到3个伙伴，每次流程相同，但问题越来越难。
- 幻想可以存在，但物理和情绪规则要稳定。孩子能接受会说话的云，但需要知道云为什么高兴、难过或改变。

### 2. 维果茨基：最近发展区和脚手架

维果茨基的关键不是"教难一点"，而是让儿童在成人、同伴、语言和工具的帮助下，完成自己暂时还不能独立完成的事。

**内容难度公式**

内容难度 = 儿童能独立理解的部分 + 在提示下能理解的下一步。

**脚手架式叙事**

1. 主角遇到一个刚好有点难的问题。
2. 主角先尝试，失败或卡住。
3. 伙伴、照护者、工具或环境给出提示，而不是直接替他完成。
4. 主角再试一次，用自己的动作完成。
5. 结尾让儿童预测、复述或迁移到生活场景。

**创作规则**

- "教学"不要讲成道理，应当表现为：看见问题 -> 试一试 -> 得到提示 -> 再试 -> 验证结果。
- 互动问题要具体："小兔下一步先拿红积木还是蓝积木？"优于"你学到了什么？"
- 主角不应是完美英雄，而是比目标儿童"稍微多会一点"的同伴。

### 3. 埃里克森：故事主题选择器

| 年龄 | 核心冲突 | 推荐主题 | 避免主题 |
|------|----------|----------|----------|
| 0-1.5岁 | 信任 vs 不信任 | 温暖、可预测、稳定回应、熟悉仪式 | 突然惊吓、陌生面孔快速切换、无人回应的哭泣 |
| 1.5-3岁 | 自主 vs 羞耻/怀疑 | "我自己来"、可以选择、生活小任务 | "你不行我来"、嘲笑笨拙、羞辱大小便或吃饭 |
| 3-6岁 | 主动 vs 内疚 | 鼓励尝试、犯错可修复、想象和计划 | "做错了就没人喜欢你"、把探索说成捣乱 |
| 6-12岁 | 勤奋 vs 自卑 | 练习、策略、合作、努力后进步 | 能力标签、比较羞辱、只赞天赋 |
| 12-18岁 | 身份 vs 角色混乱 | 自我探索、多元可能性、价值选择 | 单一成功定义、刻板性别/职业/人格标签 |

**核心洞察**：3-6岁最需要"我可以尝试，失败了也能被接住"；6-12岁最需要"我通过练习变得更有能力"。

### 4. 依恋理论：安全基地和情绪共调节

Bowlby 和 Ainsworth 的依恋理论提醒创作者：儿童的探索能力来自安全关系。依恋不是给孩子贴标签，而是理解儿童如何在安全、分离、重聚和安抚中调节情绪。

**安全型内容结构**

- 主角有稳定的安全基地：家、照护者、朋友、教室、树屋、固定仪式。
- 冒险可以离开安全基地，但结尾要有重聚、修复或被理解的时刻。
- 冲突后要展示"关系修复"：道歉、解释、拥抱、重新约定、一起收拾。
- 旁白和角色声音保持稳定、温暖、可预测。
- 情绪先被命名和接纳，再进入解决问题："你很害怕，因为声音太大了。我们先捂住耳朵，再看看是什么。"

**避免**

- 不用"你不乖就不要你"、"妈妈不喜欢你了"、"再哭就走掉"。
- 不把分离、遗弃、迷路、被怪物追赶当低龄儿童的廉价刺激。
- 不用尖锐音效、怪异变声和过密剪辑制造兴奋。

### 5. Bronfenbrenner：生态系统视角

儿童发展发生在多层环境中：家庭、同伴、学校、社区、媒介平台、文化和政策。内容创作要避免把儿童孤立成一个"小脑袋"。

**创作应用**

- 亲子内容要给照护者可执行的话术，而不是只要求孩子改变。
- 学校/幼儿园内容要体现同伴互动、规则协商和集体生活。
- 城乡、家庭结构、语言文化、能力差异都要被看见，避免默认只有一种"正常童年"。
- 当内容引发问题行为时，先检查节奏、奖励机制、观看场景和成人陪伴，不要只责怪孩子自控力差。

### 6. 蒙特梭利：有准备的环境和自主探索

蒙特梭利的价值在于提醒创作者：儿童不是被灌输的容器，而是在有秩序、有材料、有自由边界的环境中主动发展。

**画面与交互原则**

- 背景简洁，核心物体清楚，减少无关装饰。
- 自然、温和、可辨识的颜色优于荧光刺激。
- 真实生活动作很有价值：倒水、擦桌、穿鞋、分类、摆放、照顾植物。
- 给儿童有限选择，而不是无限选择：二选一、三选一、按步骤完成。
- 重复不是无聊，重复是建立秩序感、掌控感和熟练度。

## 四、儿童媒介内容规则

### 0. 从"儿童安全"到"儿童爱看"

儿童心理学不能只用来避雷。它的更高价值，是解释儿童为什么会主动靠近某种内容、反复观看、模仿角色、要求续集，并把内容带入自己的游戏和语言里。

儿童爱看的内容通常不是"更刺激"，而是同时满足以下心理机制：

| 机制 | 儿童感受 | 内容做法 | 风险边界 |
|------|----------|----------|----------|
| 熟悉感 | 我认识它，我知道接下来会怎样 | 固定角色、固定开场、固定口头禅、重复结构 | 不要重复到完全无变化 |
| 小惊喜 | 咦，这次有一点不一样 | 在熟悉结构里改变一个物体、表情、声音或结果 | 不用突然惊吓和尖叫 |
| 能力感 | 我猜对了，我也会 | 让儿童能预测、跟说、跟唱、跟动作 | 不把失败做成羞辱 |
| 自主感 | 我可以选，我能影响故事 | 二选一、找一找、数一数、帮角色决定下一步 | 不给低龄儿童过多选项 |
| 关系感 | 我喜欢这个角色，它像朋友 | 角色性格稳定，有弱点、有情绪、有修复关系的能力 | 不制造依恋恐吓和抛弃焦虑 |
| 情绪释放 | 好好笑、好紧张、终于好了 | 温和冲突、滑稽动作、夸张表情、可修复的小麻烦 | 不用恐怖、羞辱、暴力刺激 |
| 模仿入口 | 我现在就能玩一遍 | 简单动作、口头禅、手势、生活任务、角色扮演 | 不设计危险动作 |
| 同伴谈资 | 我想讲给别人听 | 鲜明角色、可复述桥段、谜题、收集元素、系列化 | 不诱导攀比和消费焦虑 |

### 年龄段吸引力密码

| 年龄 | 爱看的核心 | 可用设计 | 少用设计 |
|------|------------|----------|----------|
| 0-2岁 | 声音、脸、节奏、重复、亲密互动 | 儿歌、躲猫猫、拟声词、照护者回应、真实物体 | 独立长时间屏幕观看、复杂剧情 |
| 2-3岁 | "我自己来"、模仿、秩序、命名 | 穿鞋、洗手、收拾、选择、简单口头禅 | 抽象规则、过度说教 |
| 3-6岁 | 假装游戏、角色关系、重复桥段、小麻烦被解决 | 拟人角色、固定搭档、三段式重复、可跟唱跟跳、温和滑稽 | 多线叙事、过强恐惧、道德说教 |
| 6-8岁 | 规则、公平、挑战、完成任务 | 闯关、找线索、合作、技能升级、简单反转 | 只讲情绪不做任务 |
| 8-12岁 | 同伴、能力、秘密、收集、策略、身份感 | 团队冒险、推理、阵营、装备、地图、连续世界观 | 低幼化口吻、单集无成长 |
| 12岁+ | 身份探索、观点、复杂关系、风格认同 | 多视角、价值选择、角色弧光、社群话题 | 居高临下教育 |

### "爱看"的内容公式

```text
儿童爱看 = 适龄安全
        + 熟悉结构
        + 微小变化
        + 可预测参与
        + 角色依恋
        + 情绪释放
        + 可模仿动作/语言
        + 系列期待
```

创作时先确保安全和适龄，再刻意设计"儿童愿意回来"的理由：角色有没有口头禅？孩子能不能跟着做一个动作？每集有没有一个固定仪式？这集和上一集相比，变化点是什么？孩子看完能不能马上复述或玩出来？

### 1. 短视频和动画

- 低龄儿童更适合短、清楚、重复、可预测的内容。15-60秒短内容可以用于单一动作或单一概念，但不要把高频刺激当作质量。
- 5-10秒可以有一次"意义推进"：新动作、新表情、新问题、新反馈。不要用闪烁、尖叫、突然放大来抢注意。
- 对2-5岁，优先设计可共同观看、可暂停讨论、可迁移到现实生活的高质量内容。
- 对2岁以下，不把内容定位为独立屏幕早教。若必须做，应面向照护者共同使用，强调亲子互动、语言回应和现实物体探索。
- 避免快节奏、暴力、过度分散注意的App式设计；不要用无限循环、随机奖励和强音效诱导沉迷。

### 2. 绘本

- 0-3岁：真实物体、动作词、拟声词、重复句式、翻页预测。
- 3-6岁：角色目标清楚，情绪表情明确，冲突可修复，结尾有安全感。
- 6-8岁：章节可以变长，但每章要有明确问题和具体线索。
- 8-12岁：可以加入多角色动机、团队协作、策略推理和价值选择。

### 3. 游戏和互动产品

- 核心机制要服务发展目标：分类、轮流、记忆、空间、语言、情绪识别、合作。
- 奖励应指向努力、策略和进步，不只给糖果式积分。
- 失败反馈要可修复："再试一次，先找最大的那块"，不要羞辱或嘲讽。
- 对低龄儿童，操作负担要小于认知目标；不要让复杂按钮吞掉学习任务。

## 五、创作前的五问

1. 目标儿童年龄是多少？这个年龄最核心的发展任务是什么？
2. 这条内容主要支持哪个领域：认知、语言、情绪、社会性、动作、自理，还是关系安全？
3. 难度是否处在最近发展区：孩子独立能懂一部分，在提示下能迈出下一步？
4. 主角有没有安全基地？冲突后有没有情绪接纳、关系修复或稳定收尾？
5. 孩子为什么会爱看：熟悉感、小惊喜、能力感、关系感、幽默、模仿入口分别在哪里？
6. 看完之后，儿童能在现实生活中做什么、说什么、试什么？

## 六、综合创作清单

### 角色设计

- [ ] 主角发展水平比目标儿童稍高一点，不是全能英雄。
- [ ] 有稳定安全基地：家、照护者、朋友、教室、树屋或固定场所。
- [ ] 表情清晰可读，情绪词明确。
- [ ] 声音温暖、一致，角色音色不频繁突变。
- [ ] 同一角色在系列中保持性格、能力和关系连续。

### 故事结构

- [ ] 低龄内容采用线性叙事，无闪回、平行叙事和复杂时间跳跃。
- [ ] 使用重复结构 + 渐进变化。
- [ ] 主角经历：尝试 -> 遇到困难 -> 得到提示 -> 再试 -> 完成或修复。
- [ ] 冲突不以羞辱结束，结尾回到安全、理解或可继续尝试的状态。
- [ ] 每次画面变化都有语义功能，不只为了刺激。

### 吸引力设计

- [ ] 有固定开场、固定口头禅、固定动作或固定收尾仪式。
- [ ] 每集至少有一个儿童能预测、跟说、跟唱、跟动作的参与点。
- [ ] 在熟悉结构里加入一个小惊喜，而不是靠突然惊吓抢注意。
- [ ] 角色有稳定性格、可爱弱点和可修复的小麻烦。
- [ ] 看完能被儿童复述、模仿或带入线下游戏。
- [ ] 系列内容有可期待的变化：新朋友、新任务、新地点、新道具或新技能。

### 画面与声音

- [ ] 背景简洁，主体突出。
- [ ] 颜色温和、自然、可辨认，少用荧光和高闪烁。
- [ ] 物体变化有过渡，物理规则相对稳定。
- [ ] 声音层次清楚，避免尖锐、突然、过密。
- [ ] 旁白不要抢走儿童自己的观察空间。

### 教育性

- [ ] 不直接灌输结论，先给儿童观察和预测的机会。
- [ ] 用具体任务承载知识：分类、比较、数数、轮流、表达需求、安抚情绪。
- [ ] 难度可被提示降低，可被重复练习。
- [ ] 夸奖努力、策略、坚持、合作和修正，而不只夸"聪明"。

### 媒介健康

- [ ] 内容可暂停、可讨论、可迁移到线下活动。
- [ ] 不依赖无限循环和随机奖励。
- [ ] 不用快速剪辑、强音效和悬念恐吓维持观看。
- [ ] 给照护者可执行的共看提示或亲子延展动作。

---

## 七、创作红线

1. 不能使用"你不乖就会被抛弃/不喜欢你了"的叙事。
2. 不能拿孩子和"别人家孩子"比较，尤其是6-12岁的能力发展阶段。
3. 不能把哭、害怕、生气说成"不准有"。情绪需要先被命名和接纳。
4. 不能用羞辱大小便、吃饭、穿衣、说话慢等方式推动剧情。
5. 不能给前运算期儿童使用快速闪回、多线叙事、复杂隐喻。
6. 不能用物体突然变形、物理规则混乱来替代真正的想象力。
7. 不能用尖锐音效、怪异变声、突然惊吓制造低龄刺激。
8. 不能把屏幕内容包装成0-2岁儿童的独立早教替代品。
9. 不能用"天生聪明/天生笨"解释成功或失败。
10. 不能把儿童问题简单归因给儿童本人，忽略家庭、同伴、媒介和环境。

### AI动画提示词骨架

```text
为{年龄}儿童创作一个{时长}的线性小故事。
发展目标：{认知/语言/情绪/社会性/自理/动作}。
主角：比目标儿童稍微多会一点，但会犯错、会求助、会再尝试。
结构：安全开场 -> 具体问题 -> 第一次尝试 -> 温和提示 -> 再次尝试 -> 情绪接纳/关系修复 -> 安全收尾。
吸引力：固定口头禅/动作 + 一个可预测参与点 + 一个小惊喜 + 一个可模仿的线下动作。
限制：无闪回、无抛弃威胁、无尖锐音效、无突然惊吓、无复杂隐喻；画面具象、节奏稳定、表情清晰。
结尾：给照护者一个可线下延展的问题或动作。
```
