# 短剧桥段素材库

让人从可靠素材中获得更多可选择、可组合的创意。完整桥段保存语境，借鉴可以取其中有作用的一部分。取舍依据是当前创作目标与人物可信的行为，已选参考可以只取局部、重新构思或放弃。原作事实、分析判断、AI 新构思分别保存；作品是否好看由实际观看与人的取舍检验。

## 入口与工具

- 从 `~/.config/gg-drama-library/config.json` 的 `library_root` 定位素材库；`--config` 可选另一份配置。缺配置时询问一次目录，用 `scripts/library.py configure --root /指定目录` 保存，再 `init`。有效配置跨任务复用，不依赖当前目录。
- 改配置不搬迁旧库；外置卷离线停止写入。保留原片和已有记录，示例不冒充真实入库素材。
- 工具负责配置、数据落盘、校验与全量目录导出；素材选择由 Harness 浏览、阅读和理解，无专用匹配或评分程序。

## 按任务读取

| 任务 | 指引 |
| --- | --- |
| 采集、单集与整剧分析 | [采集与分析](references/ingest-analysis.md)、[数据契约](references/data-contract.md)；视听证据交给 gg-video-analysis |
| 找参考、匹配开头、情节启发与创意组合 | [素材启发](references/retrieval.md) |
| 采集或比较视频表现 | [数据快照](references/performance-data.md) |
| 配置、目录导出、校验 | `python3 scripts/library.py --help`；[验收标准](references/acceptance.md) |

用户为自己的故事找办法时默认给参考支持的点子；明确只查原例时只交付原例。人负责筛选、组合、定稿，不要求先提交专业分析，也不自动进入改稿或媒体生成。

构思消费采集成果：优先读取分析文本、标签、校对对白与跨集关系，文字资料可正常批量、并行读取。默认不加载图片，不运行 ASR、OCR、抽帧或视频重分析；缺口标明待补，不自动切回采集。用户要求看图或核验原片时，再按 [素材启发中的资源约束](references/retrieval.md#资源约束) 进入对应分析任务，不缩窄创意来源范围。

## 共同底线

- 原片、对白、画面和时间范围必须可追溯；缺集、试看、转述和未知保留区别。判断可有不确定性，出处与数据不能编造。
- 原作前情与人物所知按实际时间保留。新构思可以重建情境，不能倒改原作事实。
- 采集按原片顺序保留可核对的场景、对白、动作、铺垫与后果；分析推断附依据，不写可替换物件或改造公式。创作适配留在构思阶段。
- 表现数据附来源、日期和比较口径，受众推断与真实画像分开；高播放不证明单个桥段的因果效果。
- 来源采集使用当前可用且获授权的能力，浏览器遵循项目规则；收费处理和外部上传遵循当前授权。
- 入库按数据契约校验后导出目录；结构校验不替代视听观察或创意判断。用户反馈只记录已表达的内容，兴趣不等于采纳。
