# 专栏发布

适用于普通专栏或充电专栏。视频走 [视频发布](publish-flow.md)。台账写入同一 `ledger_path` 的「专栏发布记录」。

## 硬规则

1. 先查台账专栏段和后台图文管理；同正文源、同标题、同 `dyn_id/rid` 不重复发。
2. 开场面向读者，直接给人物、冲突和关系转折。禁止“小说版开始连载”“本篇收录”“以下为正文”等后台口吻。
3. Markdown 空行不能原样进 B站 ProseMirror。每个自然段只保留一个真实换行。
4. 分享卡、正文、标题、充电权限、原创声明、AI 辅助声明提交前一次读回。
5. 充电专栏默认向非充电用户开放约 50% 试看；截点落在完整自然段之后，优先全文 45%–55% 的剧情钩子。
6. 只点页面 `发布` 一次。`/x/dynamic/feed/create/opus` 返回 `code=0` 且拿到 `dyn_id/rid` 即成功。
7. 已发布专栏排版或文案问题只编辑原 `rid`，禁止删除重发。
8. 成功后立即追加台账；未记录 `dyn_id/rid`、正文源、分享卡和权限，不算完成。

## 一次备齐

- 标题：作品名、序号、本篇钩子；不写内部文件名。
- 导语：1–3 句，人物处境 -> 眼前冲突 -> 关系转折。
- 正文源：明确到章节文件和首尾锚点。
- 分享卡：默认 1 张，放正文最前，记录路径和 sha256。涉及小说分享卡时先读项目小说分享卡规则。
- 权限：普通公开或充电专属。

## 主路径

本地组稿与归一化 -> 页面插图和正文 -> 内容/DOM/视觉三重自检 -> 点一次发布 -> 接口受理 -> 写台账。
