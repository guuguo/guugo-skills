# 对白与节奏：同时防过载和空等

## 三个单位不要混淆

- 全集：主事件和情绪如何起伏、关系或笑点如何回收。
- 节拍：发生一次新的信息、动作后果、选择或可读的情绪变化。
- 生成单元/镜头：承载节拍的技术切片。一个节拍可跨单元，内部切镜也可只观察同一动作。

节奏是期待被建立、改变和兑现的速度，而不是每秒动作数量。静止人物可以在作出决定，快切动作也可以毫无新信息。

## 度量口径

| 指标 | 怎么读 | 不可推出 |
| --- | --- | --- |
| 全段对白密度 | 可发声文本字数/段时长，按段显示起伏 | 字少必慢，字多必好看 |
| 局部发声速度 | 某句可发声单位/实际口播窗口；用原配音优先 | 全集均值能证明长句够说 |
| 回合数 | 说话者/说话意图转换，含系统提示音的回应 | 越多越好；同一独白切镜不变成多回合 |
| 有效节拍 | 观众新增的信息、因果结果、选择或情绪改变 | 摄影机移动或每个微表情都算新推进 |
| 无对白动作 | 完整动作路径及结果所需时间 | 无对白就是空拍 |
| 反应余量 | 刺激后观众读懂人物选择所需停顿 | 每句后统一补半拍或两秒 |

汉字计数不含标点；数字、英文、笑声、系统提示按实际读法另记，不悄悄漏掉。对白列表需要人工核对说话人与引号内引用，避免只靠正则漏掉短命令。计数是证据辅助，不是质量判分器。

没有配音时给估时范围与口吻假设，可用正常中文约3–5字/秒做粗排起点，但不同角色和语境差异大，不能设成门禁；拿用户认可样本校准。系统语音、笑声、换气、换人也占声道时间。
不主动为计时调用收费TTS或生成。文件没实测就写“估时”，别伪装成音频结果。

## 看关键路径，而不是机械求和

- 一句命令与举手可以并行；边说边把袋子推过去通常不必分别加满两次时间。
- 交接要先接稳再松手，否认后的回看必须先发生才可被抓包；这类前后关系按串行算。
- 总预算 = 必须串行的关键路径 + 必要理解/反应 + 换场成本；只扣除明确可并行的部分，不从每个动作任意减时。
- 同一复杂变形同时要求高速运镜、遮挡穿越和长对白，逐项说明冲突；不能仅凭“AI可能不行”就删用户选择的钩子。

## 双向检查

### 过密

指出是词多、发声窗口短、换人太频繁、动作先后太多，还是观众来不及理解；不能统称“信息量大”。

检查：
- 发声时是否还必须吞咽、喘气或完成复杂身体动作？
- 反转、取物、递接、反应是不是在同一瞬间叠完？
- 上一幕末已完成的走位，下幕是否重演？
- 把完整回合削成一句指令后，是否失去误会、笑点或关系变化？

修复顺序：删除重复流程/解释 → 合并可并行动作 → 省略低价值过渡 → 移出并列弱桥段 → 必要时协商时长。不要一开始就全面砍对白或加速口播。

### 过空

逐个可疑窗口问：“如果缩短这里，观众会少知道什么，或读不出谁的选择？”

有收益的停留：
- 等对方接住后才松手；
- 发现自己嘴硬被抓包；
- 原本要退却决定留在近处；
- 紧张场景里危险或期待仍在改变。

可疑的空等：
- 看完再看、已经放松又叹气，没有新的触发；
- 扶住道具，再拍确认握稳，最后才做真正动作；
- 提笼/收翼等已结束，却为填满单元延长静止；
- 对同一个情绪换三个景别，每个都安排独立停顿；
- 每句对白必须说完、等两秒、才换人。

少对白但动作不断产生新结果，不判空。大量动作只重复准备，仍可判空。需要几秒由具体表演决定，不设“超过N秒必删”的阈值。

## 提示词额外检查

- 剧情中“一愣”“收翼”“反应一下”在提示词里被分配多少秒？占用是否与叙事收益相称？
- 新景别是在揭示新信息还是重复同一状态？运镜和快切不能冒充节奏修复。
- 时间标注与自然语言冲突吗，如一秒却写“缓慢、停顿、凝视”？
- 指令里同时有“持续不动/不微笑”和“主动回应”时，是角色神态克制还是整个身体被锁死？保留设定，不把克制写成无行动。
- 各段时间相加正确仅证明算术；对白可说完仅证明口播，两者都不能证明观看节奏成立。
