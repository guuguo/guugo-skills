# AI 短剧对白与节奏评审

统一承接原 ai-drama-delicacy 与 ai-ambiguity-drama-review。只有本入口维护评审流程，旧名称仅作兼容跳转。

目标是判断**观众是否持续获得可理解的推进和指定的情绪回报**，不是把对白越删越少，也不是把每秒塞满动作。细腻不等于慢，紧凑不等于高语速，多切镜不等于有节奏。

## 先确定评什么

- 读取完整单集、必要前情、角色关系阶段、用户认可的参照版本及当前制作状态。区分原始脚本、导演提示词、实际配音/成片；不同版本不要混成同一证据。
- 用户指定第二集等正例时，先找其真源和实际时长证据，解释有效机制，再评当前稿。认可节奏是用户反馈，不等于所有时间标注均实测，也不证明流量好。
- 评审/诊断只读；明确要求优化/改写才改文件。提示词评审不授权偷偷改剧情对白；改动真源需要对应授权。
- 同时拿到脚本和提示词时，先校对白、事件顺序、动作起止和物件状态，再检查时间与镜头是否扭曲表演。只拿到一种材料就声明另一层未验证。
- 全集是叙事单位，生成单元是生产切片。时长上限来自当前模型/项目，不默认15秒。允许桥段跨段；既不强迫每段独立闭环，也不擅自改用户锁定的段数/时长。
- 先读 [对白与节奏双向检查](references/dialogue-rhythm.md)；按 [评审量表与证据](references/review-rubric.md) 给出结论。

## 同一轮看六个方面

1. **事件与因果**：谁要做什么，阻力如何改变下一步，结尾有什么结果；小任务是日常戏常用机制，不是所有题材的硬模板。
2. **对白与回合**：像人物此刻会说的话吗？刺激→回应→反转→反应能否完整读懂？保留有辨识度的长句、短答、嘴硬、打断，不只按字数删。
3. **节奏与密度**：同时查“来不及”和“没事发生”。对白密度、发声速度、有效事件推进、反应时长分别看；剪辑次数不能代替新信息。
4. **细腻度**：用信息差、选择成本、生活后果和物件回收提供互补证据，不用多次凝视或旁人重复解释冒充细腻。需要深入时读 [细腻度方法](references/delicacy-method.md)。
5. **暧昧度与喜剧**：先明确用户要自然甜感、高张力、公开双层可读、关系兑现还是非关系喜剧。保留建立→偏离→反转→人物反应的完整笑点，以及靠近/拒绝/接受的关系变化；不是越亲密越高分。非暧昧题材该维度可不适用。
6. **表演与编译一致性**：关键动作是否有明确对象、起止及连续路径；声源、左右、物件能否对应。提示词把一瞬反应拉成数秒、把动作拆成重复准备，属于编译问题，不倒逼删掉剧情。

## 节奏修复优先级

- 先指出确切失败窗口、观众此刻新增知道什么、何时不再有变化，再提出修改。
- 过满：先省略低价值流程、重复解释和并列弱桥段；保住核心笑点的完整回合。不要把“让开→跟上→吐槽”压成一句命令。
- 过空：先取消重复准备和冗余停顿、恢复已被误删的互动、重分已有节拍；不是自动加台词、加特效、换地点或加支线。
- 只在新的短句确实改变误会、选择或后果时补话，写清它的作用；解释画面已表达的结果不能算新增推进。
- 能并行的短话和简单手势可以同拍；需要看清先后的交接、观察→抓包、松手→接住不可随意并行。
- 开场钩子与整段分开计时。钩子兑现后进入下一拍；不要把三秒钩子扩成十五秒等候。具体秒数以用户选择为准，不推广成所有作品硬门槛。
- 若锁定总长与可用内容仍冲突，明确给出剪短/重分片或恢复有价值内容的取舍，不能靠静止撑满或擅自改变规格。
- 需要完整改稿时读 [最小修改手册](references/optimization-playbook.md)，交付完整可用稿，不让用户拼零散句子。

## 输出

先给结果，再按请求深度给证据，不强制每次完整长报告：

1. 结论：应保留的效果、主要失败边界、是否需要修改；分别声明文本判断/音频计时/成片目检已完成哪些。
2. 对照：有用户指定正例就比较机制与密度变化，不拿不同版本总字数直接断优劣。
3. 问题表：位置/时间窗｜原句或动作｜新增状态或停滞证据｜观感/风险｜最小修法。
4. 涉及时长时列逐关键窗口预算：对白字数与回合、实测或估时、必须串行的动作、可并行部分、反应是否新增信息。计数方法和系统声必须交代。
5. 细腻/暧昧：保留的选择差、信息差和回收；没有该目标就不强加。
6. 授权改稿才给完整优化稿与变更理由；验证失败边界及未检查内容，不让旧版本结论自动放行新稿。

不要用单一总分或PASS遮盖未知。评分仅在用户需要时使用；时间可容纳、节奏有推进、目标关系/笑点成立是不同结论。
本技能不生成图片、配音或视频，不上传、不重跑、不改平台卡片。用户另行授权后交给相应执行流程，绝不以“评审通过”视为消耗积分的许可。
