# 角色资产方案

本方案用于抖音写实情感短片的人物生成、复用与锁定。目标是用一张图同时提供高权重脸部锚点、体型、服装和背面信息，降低后续分镜与视频中的漂脸、变装和背影错人。

## 默认首张角色图：超大主脸特写＋正背偏侧双全身

除非用户另有指定，每个需要跨镜头保持一致的角色，默认先生成一张横版“超大主脸特写＋正背偏侧双全身”一体设定图：

- 建议画幅为横版 `16:9` 或接近 `2:1`，使用干净暖白或中性浅灰影棚背景，不写人物名和说明文字。
- 左侧约 `60%–62%`：正面完整头部超大特写。以头发最高点（有兽耳或头饰时含其最高点）至下巴的**头部本身**计量，目标占整张画面高度约 `82%–88%`，不把脖子、肩膀或胸部算入；上方留约 `3%–5%` 安全边距。下缘仅保留少量肩颈与衣领，肩膀大部分在画外，不展示胸部或大片胸口开领区域。完整保留头发顶部、发际线、主要耳部／耳尖／耳饰与下巴，禁止以裁头、裁耳换取放大。眼型、鼻形、唇形和脸部轮廓清楚，作为唯一高权重主脸锚点。
- 完整头部与脸部辨识优先于凑满比例；兽耳、蓬松发型或头饰较高时，以完整外轮廓为边界微调缩放，仍压缩肩胸区域，不退回普通头肩照。服装整体及颈部配饰由右侧全身图展示；用户要求胸前结构与脸一起锁定时再启用含胸分支。
- 主脸采用写实真人摄影质感。妆容服从角色身份并保持克制；保留自然毛孔、轻微肤色不均、眼下纹理、真实唇纹和少量合理微瑕，禁止塑料磨皮、蜡感、密集重复裂纹、颗粒脏纹或过度锐化。
- 右侧约 `38%–40%`：同一人物、同一服装、同一体型的两张等比例全身图，依次为正面偏侧全身、背面偏侧全身。两张都相对严格正面／背面偏转约 `15°–25°`，必须明确露出侧向轮廓；默认方案禁止生成完全正面或完全背面的僵直全身图。
- 正面偏侧以服装正面和一侧轮廓为主；背面偏侧以肩背、发长、服装背面和另一侧轮廓为主。肩线、髋部和双脚朝向共同形成偏侧关系，不能只转头而身体仍完全正对或背对镜头。
- 两张全身图使用统一身高、统一落脚线和放松自然站姿，双手、裤脚、裙摆和鞋完整可见；禁止裁脚、遮挡服装主体、严格证件式站姿或夸张剧情动作。
- 右侧全身小像只承担体型、发型长度、服装、鞋和正背偏侧轮廓职责，面部必须为平滑自然肤色的无五官曲面：不出现眼睛、眉毛、鼻子、鼻孔、嘴巴、睫毛或暗示性五官。保留正常头型、耳朵、发型和必要头部配饰，不能生成黑洞、模糊涂抹或融化式恐怖无脸。只有左侧主脸特写允许出现五官。
- 三个人像必须保持同一角色设定：年龄、头型、发型、发色、肤色、身高体型、衣服版型、衣长、裤长、配饰和鞋款一致；身份五官只由左侧主脸锚定，不要求右侧无五官小像重复五官。

这张图是默认首张角色图和视觉身份母版。它把主要画面面积让给唯一主脸，同时用前后偏侧全身锁定体态、妆造与背面信息；无五官小像避免多张低清小脸与主脸竞争身份权重。

多表情卡是[仅在用户明确指定时启用的非默认方案](multi-expression-card.md)，不得因下游需要表情范围或项目旧默认规则自动追加。单集定妆照、分龄图、关系参考图和严格三视图均为按需补充，不把不同资产职责混为一谈。

## 可选分支：主脸含胸近景＋正背偏侧双全身

当用户明确要求主肖像包含胸部，或胸甲、领口、围巾、胸前装置等结构需要与脸一起锁定时，可在成年角色上启用本分支。它只改变左侧主肖像的取景，不自动改写人物体型、服装覆盖度或右侧双全身职责；没有上述需求时仍使用默认完整头部超大特写。

- 建议画幅为横版 `16:9`。左侧约 `52%–55%`：正面“头部＋胸部”近景，完整保留头顶、发际线、主要耳部或耳饰、下颌、肩颈、关键颈部配饰和完整着装胸部；画面下缘停在胸部下缘附近，不继续露出腰腹、髋部或大段手臂。
- 主脸仍是唯一高权重身份锚点，脸部尺寸与清晰度不得因纳入胸部而降级；禁止退成普通半身照，也禁止裁成只见脸、不见胸前服装结构的头像。
- 胸部必须完整着装并采用中性自然参考姿态，只用于锁定成年角色的体型轮廓和胸前服装／装备结构；禁止裸露、透明材质、内衣化改造、刻意挤压、挑逗表情或性感姿势。
- 右侧约 `45%–48%`：继续使用默认方案的正面偏侧、背面偏侧无五官双全身；偏转角度、统一落脚线、手脚完整、体型妆造一致和无五官规则均不变。
- 翅膀、披风、背负装置等背部关键结构以右侧背面偏侧全身为完整验收位；左侧近景只保留自然可见部分，不为展示背部结构继续放宽到腰腹构图。

本分支不是新的默认首图，也不替代单集定妆照。用户只要求“脸更大”时使用默认方案；用户要求严格侧面或建模校准时使用后述三视图方案。

## 备选方案：近景特写＋三视图

当用户明确要求“三视图＋近景特写”，或角色会频繁出现严格侧脸、复杂转身、建模式空间校准和多机位动作时，改用横版“近景特写＋三视图”一体设定图：

本节是用户明确启用后的例外；未明确启用时，不得为了生成方便把默认的前后偏侧双全身退回为完全正面／完全背面。

- 建议画幅为横版 `16:9`，干净暖白或中性浅灰影棚背景，不写人物名和说明文字。
- 左侧约 `40%–45%`：正面头肩近景，完整保留头顶、发际线、双耳、下颌与肩颈；中性自然表情，皮肤纹理清楚，供后续锁脸。
- 右侧约 `55%–60%`：同一人物、同一服装、同一比例、同一落脚线的三张全身图，依次为严格左侧面、正面、背面。
- 三视图双手自然下垂，手和鞋完整可见；禁止用四分之三侧身替代严格侧面，禁止裁脚、遮脸或姿态夸张。
- 四个人像必须是同一身份：脸型、五官、年龄、发型、发色、肤色、身高体型、衣服版型、衣长、裤长和鞋款一致。

原“近景特写＋三视图”方案不再作为普通角色的默认首图；只有严格侧面与空间校准价值高于主脸面积时才启用。

## 参考图职责

存在多张参考图时，在提示词中逐张声明职责并明确优先级：

1. **身份参考**：决定人物的脸、年龄、发型、肤色和体型，优先级最高。
2. **妆造参考**：只决定服装、鞋、配饰和必要的职业外观，不得改写身份。
3. **版式或风格参考**：默认只决定“左侧超大主脸＋右侧前后偏侧无五官双全身”的排布、背景和摄影质感；启用含胸分支时只决定“左侧头部＋胸部近景”的取景比例；启用备选方案时才决定“左近景＋右三视图”的排布。不得把版式参考人物的长相、发色、瞳色、体型、服装或附件迁移给目标角色。

不要仅凭文字概括本地参考图。实际生图时应把参考图作为图像输入，并在生成前让其进入当前工具上下文。

## 默认不烘入身份母版的内容

- 头盔、手机、奖状、药盒、扫帚、电动车等剧情道具；
- 汗水、雨水、血迹、伤口、泪水、污泥等单场状态；
- 挥手、奔跑、哭喊、跪地等剧情动作和极端表情；
- 场景背景、其他人物、字幕、标签、Logo 和水印。

道具应先生成独立干净母版。需要锁定“人物＋服装＋道具”的组合时，再补单集定妆照或关系参考图，避免带道具版本反过来污染人物身份。

## 何时追加其他角色图

- 用户明确指定多表情卡时：读取 [多表情卡方案](multi-expression-card.md)，继承已确认身份制作；仅需要多种情绪近景不自动触发生成。
- 同一人物跨年龄或跨造型时：每个关键年龄或造型分别生成身份母版，并明确上一阶段身份图是脸部连续性参考。
- 头盔、口罩、帽子遮挡脸部时：身份母版保持无遮挡，另补佩戴状态定妆照。
- 默认卡无法稳定提供严格侧面时：补“近景特写＋三视图”备选卡，不重做已经确认的主脸身份。
- 只有一个远景且无台词的背景人物：可不生成完整身份母版，按实际复用风险降级。

## 保存与验收

- 用户未确认的人物图放在 `候选/`；确认后再复制或移动到项目的正式锁定目录。
- 默认方案文件名建议：`<角色名>-<年龄或阶段>-<核心服装>-超大主脸与正背偏侧双全身-无五官小像.png`。
- 含胸分支文件名建议：`<角色名>-<年龄或阶段>-<核心服装>-主脸含胸与正背偏侧双全身-无五官小像.png`。
- 备选方案文件名建议：`<角色名>-<年龄或阶段>-<核心服装>-近景与三视图.png`。
- 默认方案验收：主肖像区占画面宽度约 `60%–62%`，头发最高点（含兽耳／头饰）至下巴的头部本身占画面高度约 `82%–88%`，上方有安全留白，头顶、耳尖、耳饰和下巴完整；下缘只留少量肩颈与衣领，不露胸部或大片肩膀。不得用头肩整体填满画面冒充头部放大，也不得以裁切头部满足占比；主脸具备写实真人皮肤与适量微瑕，没有塑料感或重复脏纹；前后两张全身均为明确偏侧而非完全正面／背面，体型、发长、服装、配饰与鞋一致，手脚完整、同一落脚线；右侧两张脸均彻底无五官且不呈恐怖涂抹状。
- 含胸分支验收：左侧约占 `52%–55%`，头顶、耳饰、下巴、关键颈部配饰和完整着装胸部可见，画面下缘在胸部下缘附近且不露腰腹；主脸清晰度不低于默认身份锚点；右侧双全身继续满足默认方案的偏侧、无五官、同体型妆造和手脚完整要求。
- 备选方案验收：四张脸为同一身份，严格侧面、正面、背面与服装手脚一致。
- 生成后先检查文件可读、尺寸和落盘位置；若项目要求人工视觉验收，再按所用方案逐项检查。
- 任何引用该角色的正式分镜或视频提示词，应优先使用已确认的默认身份母版；需要严格侧面时再追加备选三视图，不得只引用低分辨率分镜截图。
