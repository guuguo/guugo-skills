# 角色卡

角色卡相关任务统一由本技能处理，不要求先加载抖音视频技能。角色卡用于锁定视觉身份、体型与妆造；纯人物小传、剧情创作和视频镜头编译不属于本技能。

## 工作流程

1. 读取用户给出的角色事实、已确认身份图、妆造参考与当前项目角色资产规则。区分身份参考、妆造参考、版式／风格参考；没有图时不得虚构图号或声称已锁脸。新角色可按已知设定起草，尚未确定的身份特征标为候选。
2. 按模板选择读取对应参考：未指定方案时完整读取 [角色资产方案与提示词](references/character-asset-plan.md)，采用默认大主脸卡；只有用户明确指定多表情卡时才读取 [多表情卡方案](references/multi-expression-card.md)。项目旧的默认多表情规则不构成启用。角色卡自身画幅不改变成片画幅。
3. 输出可直接使用的完整提示词，填入已知角色事实，删除未使用的参考图条目与分支说明；逐张声明实际参考图的职责，不从版式图借脸、借服装或配饰。写实为默认，用户或项目指定其他画风时据此适配质感，不擅改已锁身份。
4. 用户只要提示词时交付提示词；要求落文件时遵循项目现有资产目录。实际生图须在用户授权范围内调用当前可用的生图工具或技能，先查看并实际传入参考图。遵守项目及平台额度边界，写提示词不代表已生成图片。
5. 修改已有卡时保留已确认身份，只调整用户指定部分。生成后查看实际图片，按选定方案检查主脸、构图、体型妆造、手脚与参考一致性；区分提示词预检、图片验收和用户确认，未确认图保留为候选。

## 模板选择

- 默认：超大主脸特写＋正背偏侧无五官双全身。主肖像以完整头部为主体，仅留少量肩颈和衣领；按参考文件的头部占比验收，不用头肩整体占比代替。
- 主肖像需含胸前服装／装备：按参考文件的含胸近景分支。
- 用户要求严格三视图或空间校准：按参考文件的近景＋三视code图分支，不混用默认双全身的偏侧与无五官约束。
- 多表情卡（非默认，仅明确指定时使用）：读取 [多表情卡方案](references/multi-expression-card.md)，使用大主肖像、悬浮档案及表情／半身姿态／物品辅助区；不要因需要视频锁脸或存在项目旧模板而自动启用。
- 单集定妆照、分龄图、关系参考图、沉浸式资料卡：优先读取项目对应模板，只加载当前所需模板；没有现成模板时围绕该资产职责编写，不强套默认一体卡。补充卡继承已确认身份；表情卡改变表情，定妆照锁定指定妆造与状态，分龄图标明年龄阶段，关系图明确人物对应关系。

具体比例、完整提示词骨架、参考图隔离、保存命名和分支验收仅在参考文件维护。不要另存一份同内容模板。

## 交付

简要说明所用方案、参考图职责，提供完整提示词或实际文件路径。生成过图片才报告图片结果；未查看或未完成验收时明确说明。不自动重跑、不自动覆盖正式身份图。
